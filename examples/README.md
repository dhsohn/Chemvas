# Examples

Sample `.chemvas` documents. Open one in Chemvas via **File ▸ Open**.

| File | Description |
| --- | --- |
| `first-scheme.chemvas` | Start here: a small benzyl alcohol oxidation drawing. [Walkthrough](../docs/FIRST_SCHEME.md) · [한국어](../docs/FIRST_SCHEME.ko.md) · [SVG](first-scheme.svg) · [PNG](first-scheme.png). |
| `template1.chemvas` | A showcase document — a Base/THF reaction scheme plus several organocatalyst structures (thioureas, a bis-CF₃ catalyst, a binaphthyl bis-amide, a phosphine sulfonate, and more). |
| `template2.chemvas` | A C–P bond cleavage reaction scheme (KOtBu / THF conditions) over a reaction arrow, with annotation text and a fluorinated diaryl­phosphine substrate. |

The first-scheme drawing is a schematic exercise, not a measured result or an
experimental procedure. Its SVG and 300 DPI PNG use the 174 mm column setting.
The editable drawing opens and exports with the core installation; recreating
its SMILES insertion steps requires optional RDKit. These examples are separate
downloads and are not included in the Python package.
