# 예제

[English](README.md)

샘플 `.chemvas` 문서입니다. Chemvas에서 **File ▸ Open**으로 여세요.

| 파일 | 설명 |
| --- | --- |
| `first-scheme.chemvas` | 여기서 시작하세요: 작은 벤질 알코올 산화 그림. [따라 그리기](../docs/FIRST_SCHEME.ko.md) · [English](../docs/FIRST_SCHEME.md) · [SVG](first-scheme.svg) · [PNG](first-scheme.png). |
| `template1.chemvas` | 쇼케이스 문서 — Base/THF 반응식과 여러 유기촉매 구조(싸이오우레아, bis-CF₃ 촉매, 바이나프틸 bis-아마이드, 포스핀 설포네이트 등). |
| `template2.chemvas` | 반응 화살표 위의 C–P 결합 절단 반응식(KOtBu / THF 조건), 주석 텍스트와 플루오린화 다이아릴포스핀 기질. |

first-scheme 그림은 도식적 연습이며 측정 결과나 실험 절차가 아닙니다. 그 SVG와
300 DPI PNG는 174 mm 단 설정으로 출력했습니다. 편집 가능한 그림은 기본 설치로
열고 출력할 수 있고, SMILES 삽입 단계를 재현하려면 선택적 RDKit이 필요합니다. 이
예제들은 별도 다운로드이며 Python 패키지에는 포함되지 않습니다.
