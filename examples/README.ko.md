# 예제

[English](README.md)

완성된 그림, 편집 가능한 입문 문서, 재현 가능한 그리기 레시피입니다.

## 출판 그림 갤러리

아래 그림은 그리기와 배치를 보여주는 합성 예제이며, 측정 결과나 실험 절차,
제안된 반응 메커니즘이 아닙니다. 세 PNG는 600 DPI 출력입니다. 종횡비를 유지하고
원고에 넣을 실제 크기에서 글자와 투고처 규격을 확인하세요. 해상도만으로 출판
적합성이 보장되지는 않습니다.

### 분자 쌍

캡션을 정렬한 아니솔 그림 두 개입니다. 아래 첨자 식별자와 위 첨자 각주 표시를
포함합니다. [PNG 다운로드](publication-pair.png).

![캡션을 정렬한 아니솔 그림 두 개](publication-pair.png)

### 독립적인 분자 파트

독립적으로 정렬한 두 분자 파트가 캡션 하나를 공유하고, 옆에는 단일 분자 블록이
있습니다. [PNG 다운로드](publication-independent-parts.png).

![독립적으로 정렬한 분자 파트와 공유 캡션](publication-independent-parts.png)

### 두 행 비교

완전한 기호식 입력–출력 두 행이 열 너비를 공유하고, 각 화살표에 라벨이 붙어
있습니다. [PNG 다운로드](publication-comparison.png).

![열을 정렬한 기호식 입력-출력 두 행](publication-comparison.png)

그림을 편집하거나 크기를 바꾸려면 [출판 그림 레시피](../docs/PUBLICATION_SCHEMES.ko.md)를
따라 재현하세요. 선택적 RDKit 없이 공개 Chemvas 명령으로 `.chemvas` 원본, SVG,
PNG와 배치·글꼴 보고서를 만듭니다. 그림마다 같은 너비로 늘리는 대신 공통 물리
배율을 유지합니다.

## 직접 그리기

[first-scheme.chemvas](first-scheme.chemvas)를 **File ▸ Open**으로 열면 작은 벤질
알코올 산화 그림을 바로 편집할 수 있습니다.
[따라 그리기](../docs/FIRST_SCHEME.ko.md) · [English](../docs/FIRST_SCHEME.md) ·
[SVG](first-scheme.svg) · [PNG](first-scheme.png).

이 그림 역시 실험 절차가 아닌 도식적 연습입니다. 그 SVG와 300 DPI PNG는 174 mm
단 설정으로 출력했습니다. 편집 가능한 그림은 기본 설치로
열고 출력할 수 있고, SMILES 삽입 단계를 재현하려면 선택적 RDKit이 필요합니다. 이
예제들은 별도 다운로드이며 Python 패키지에는 포함되지 않습니다.
