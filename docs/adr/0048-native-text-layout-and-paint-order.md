# ADR 0048: Shared compact-label anchors, native text precision and paint order

Status: Accepted for this candidate; whole-document consumer-reference approval remains blocked.

Native SaveAs interprets two-letter atom labels and compact aliases using the facing end glyph. Centering the entire Me, Ar or Cl string in the common planner produces a horizontal shift on native open. Extend the existing tBu/t-Bu/i-Pr facing-glyph rule to Me, Ar and two-letter element-shaped labels. Keep the spelling, chemistry, coordinates and collision safeguard unchanged. This is the same screen/headless planner for existing and new documents.

Serialize a trailing anchor as Right justification at the painted text advance, with explicit LabelJustification; leading anchors use Left. Do not equate left- and right-justified CDXML p coordinates. Eight Me/Ar/Cl/tBu controls, each facing left/right, were saved and reopened by separate ChemDraw 25.0.2.14 processes. Comparing actual SVG text origins in the original document frame reduces maximum horizontal error from 6.66781 pt to 0.01157 pt. The unchanged vertical error is about 1.31624 pt at 16 pt. This evidence does not establish identical glyph ink.

CDXML font sizes have twentieth-point precision. Encode the nearest representable positive value for every text emitter, refusing zero, nonfinite and overflow values. The serialization error is at most 0.025 pt; screen font metrics remain unchanged. This avoids native downward truncation without adding a second renderer or changing the consumer-reference tolerance. Full OMe first-save size discrepancies fall from 231 to zero; alignment discrepancies fall from 49 to four. The four remaining cases include charged-oxygen definitions and a two-connection generic aryl.

Font family names do not prove identical faces. Mac and Windows Arial regular/bold have different probed OpenType table hashes. The source document explicitly uses Apple SD Gothic Neo for captions, but that font is absent on Windows; no font is installed or silently substituted in the source. Empty native-document defaults were separately observed as Arial 10 pt. Native SVG family declarations do not identify every actual fallback glyph. Caption-font changes, vertical placement, remaining alignments, charge interpretation/color and second-save color changes remain unresolved.

Preserve relative Z order where a producer's flat-capped straight stroke has positive-area overlap with an opaque, axis-aligned filled rectangle. A separating-axis intersection avoids diagonal bounding-box false positives. Match active native arrows through the existing strict aliases and match rectangles by validated identity; permit numeric Z renumbering, refuse reversal or ties. This bounded check is not a general occlusion proof. In OMe, changing arrow 1241 from Z=104 to Z=0 against rectangle 1509 at Z=1 passed the preceding guard. The new guard refuses it. Independent native saves/reopens show the ordinary SVG line after the fill and the mutant line before the fill, confirming actual paint-order reversal.

No reference guard is waived. Chemical node/bond/fragment and graphic attributes, text content and the prior 308-line width fix remain preserved. Source documents and frozen candidates are unchanged. Movement/rollback product code is unchanged; the existing service test now reads the live replacement bond item and checks redraw calls. Selected whole-file regressions and bounded native automation are evidence, not full-suite or GUI acceptance.
