# Chemvas 레퍼런스

[English](REFERENCE.md)

Chemvas의 사용자 대상 상세 안내입니다. 앱 실행, 그리기 기능, 문서 형식, 출력
동작, 단축키를 다룹니다. 소개 페이지는 [README](../README.ko.md)이고, 헤드리스
명령과 에이전트 계약은 [AGENT_CLI.ko.md](AGENT_CLI.ko.md)에 있습니다.

## 실행

```bash
python app/main.py    # development tree
chemvas               # after install
chemvas --help        # root CLI help without starting Qt
chemvas --version     # package version without starting Qt
```

상단 툴바에서 도구를 고른 뒤 캔버스를 클릭하거나 드래그해서 그립니다. SMILES는
**Ring**을 고르고 옵션 바에 문자열을 입력한 뒤 **Insert**를 눌러 배치 모드로
들어갑니다. 마우스를 움직이면 미리보기가 따라오고, 클릭하면 삽입되며, `Esc`로
취소합니다. 템플릿도 같은 미리보기-클릭 방식입니다.

**File ▸ Open**으로 [`examples/`](../examples/)의 예제 문서를 열 수 있습니다.
각 파일의 내용은 [예제 README](../examples/README.ko.md)에 있습니다.

**File ▸ New Canvas** (`Ctrl+N`)는 현재 문서의 용지 크기·방향, 결합 길이,
화살표 모양 설정, 오비탈 위상 설정과 텍스트·노트 모양을 이어받은 빈 창을 엽니다.
그림 내용·파일 경로·편집 이력은 복사하지 않으며, 이후 설정 변경은 서로 독립적입니다.
앱 시작 시 새로 만드는 빈 캔버스는 기본 설정을 사용하며, 열거나 세션에서 복구한
문서는 각자의 설정을 유지합니다.

## 그리기 기능

애플리케이션에서 캡처한 짧은 워크스루 세 편입니다. SMILES 삽입과 출력은
[첫 반응식](FIRST_SCHEME.ko.md)에서 다룹니다.

**구조 그리기** — 드래그로 결합을 긋고, 포인터 아래의 결합 차수·원소 단축키로
바꾸고, 전하를 붙이고, 결합에 벤젠 고리를 융합합니다.

![구조 그리기: 드래그로 결합, 결합 위에서 2, 원자 위에서 o, 고리 융합](images/walkthrough-drawing.gif)

**화살표와 라벨** — 반응·평형·곡선 화살표, 화살표 대화상자로 입력한 라벨, 그리고
Line 도구로 그린 반응 프로파일에서 연결선이 에너지 준위의 끝점에 스냅되는
모습입니다.

![화살표와 라벨: 화살표 그리기, 더블클릭으로 라벨, 스냅되는 선으로 반응 프로파일 그리기](images/walkthrough-arrows.gif)

**선택, 이동, 회전, 정렬** — 원자를 옮기고, 노브로 선택 영역을 회전하고, 뒤집고,
정렬하고, 분배합니다.

![선택, 이동, 회전, 정렬: 이동, 회전 노브, 뒤집기, 가운데 정렬, 분배](images/walkthrough-editing.gif)

- **결합** — 단일 / 이중 / 삼중, 굵은 결합, 쐐기(wedge)와 해시(hash); 30° 각도
  스냅과 일정한 기본 결합 길이. Bond 바의 Single, Double, Triple은 기존 결합에
  표시된 차수를 적용하며, 같은 선택을 반복하면 그대로 둡니다. Undo/Redo는
  화학 구조 출력에 쓰이는 현재 결합 선택도 유지합니다.
  이중 결합에 Dotted를 덧씌우려면 안쪽/바깥쪽 일반 이중 결합이어야 합니다.
  지원하지 않는 가운데/굵은 변형에는 변경 없이 안내합니다. Single에서 Double로
  돌아갈 때 예전 이중선 위치를 기억하지는 않습니다. `d`/`Shift+D`는 이전 차수를
  유지하는 대신 점선 단일/이중 결합을 명시적으로 요청하는 기존 단축키입니다.
  결합 길이를 바꾸면 전체 분자 모델 중심을 기준으로 구조, 고리 채움과 원자에
  붙은 전하·라디칼 표시를 함께 확대·축소합니다. 자유 표시, 화살표, 노트, 괄호 등
  독립 주석의 위치는 유지하므로 그림 전체를 확대·축소하는 명령은 아닙니다.
  길이 입력창은 300 px 같은 열린 문서의 값을 예전 200 px 제한 없이 반영하며,
  단순히 포커스를 주는 것만으로 그림을 확대·축소하지 않습니다.
- **고리와 템플릿** — 벤젠, 사이클로알케인, 두 방향의 의자 형태를 실시간
  미리보기와 클릭 삽입으로 배치합니다. 보트 템플릿은 데스크톱 Ring 바가 아니라
  [`insert-template`](AGENT_CLI.ko.md)로 사용할 수 있습니다.
  융합은 장식 채움이 없는 가져온 구조도 그래프 고리에서 차지한 방향을 판단합니다.
  Ring Fill은 완전히 선택한 그래프 순환을 받습니다. 일부 호가 아닌 고리 원자/결합
  전체를 선택하세요. 고리 인식이 모호하면 수동 선택이 필요할 수 있습니다.
  Ring Fill은 Select가 활성화된 상태에서 팔레트를 여는 명령입니다. 별도의
  그리기 도구가 아니며, 이전에 쓰던 지우개를 활성 상태로 남기지 않습니다.
- **화살표** — 반응, 평형(균형, 또는 한쪽 작살을 짧게 한 편향), 공명, 곡선, 점선,
  그리고 촉매 순환용 호 화살표(90°, 180°, 270°; 드래그 중 `Shift`를 누르면 호가
  반대쪽으로 볼록해짐). 너비와 머리 크기는 문서 공통 설정이며, 바꾸면 기존
  화살표도 즉시 다시 그려지고 실행 취소할 수 있습니다. Default는 1.5 / 0.3,
  ACS는 1.2 / 0.3입니다. 너비 컨트롤은 0.1 단위이며 프리셋과 열린 문서의 설정을
  반영합니다. `Shift`는 Arrow 드래그 각도를 잠그지 않습니다. 각도 잠금은 Line
  도구에만 적용됩니다. 화살표와 선의
  끝점은 그리는 동안 줌과 무관하게 커서에서 12픽셀 안의 다른 화살표·선 끝점에
  스냅되고, 스냅된 끝에는 링이 표시됩니다. 스냅은 `Shift` 각도 잠금보다
  우선합니다. 화살표나 선(또는 그것을 포함한 선택 영역)을 옮길 때도 같은 방식으로
  연결됩니다. 끝을 다른 항목의 끝 가까이로 가져가면 정확히 이어지고, 그냥
  지나치면 포인터 위치에 놓입니다.
  스냅은 그 순간 끝점을 맞출 뿐, 지속적인 부착 관계를 만들지 않습니다.
- **화살표 라벨** — 화살표나 선을 더블클릭하면 위와 아래에 속도 상수 같은 라벨을
  달 수 있습니다. `_`는 아래 첨자, `^`는 위 첨자를 시작하고 중첩 없는 중괄호로
  범위를 정합니다: `K_{2}CO_{3}`, `H_{2}SO_{4}`, `ΔG^{‡}`. 중괄호가 없으면 다음
  공백, `_`, `^`까지 적용되므로 `K_2CO_3`는 `CO`도 아래 첨자로 넣습니다. 대화상자가
  입력하는 동안 두 라벨을 미리 보여 주므로 OK 전에 범위를 확인할 수 있습니다.
  그룹은 첫 `}`에서 끝나며 백슬래시 이스케이프는 지원하지 않습니다. 끝에 있거나
  바로 뒤에 공백이 오는 `_`·`^`는 그대로 표시됩니다(`t_ Bu`는 밑줄과 공백을
  유지하지만 `t\_Bu`는 이스케이프가 아닙니다). 각 입력란은 여러 줄을 지원합니다.
  Enter는 줄을 바꾸고 Tab은 다음 입력란으로 이동하며 OK로 편집을 적용합니다.
  줄바꿈은 미리보기, 캔버스, 내보낸 라벨에 보존됩니다. 각 입력란은 200자 제한과
  글자 수 표시가 있으며, 텍스트를 조용히 자르지 않고 어느 한쪽이라도 제한을
  넘으면 OK를 비활성화합니다. 공백만 있는 입력란은 해당 라벨을 지우며, 그 밖에는
  앞뒤 줄바꿈까지 원문을 보존합니다. 더 긴 내용은 Note를 쓰세요.
  라벨은 프리셋 변경과 Undo/Redo를 포함해 문서의 텍스트 글꼴·색 설정을 즉시 따르며
  화살표와 함께 움직입니다. 화살표에 개별 색상이 있으면 라벨에도 그 색상을 적용하며
  문서 텍스트 색보다 우선합니다. 저장 후 다시 연 라벨도 같은 설정을 사용하고,
  라벨별 글꼴을 따로 저장하지 않습니다.
- **선** — 결합이 아닌 실선, 점선, 물결선, 굵은 선. 에너지 준위 도표, 연결선,
  주석에 씁니다. 드래그 중 `Shift`를 누르면 각도가 15° 단위로 잠기고, 드래그 없이
  클릭하면 결합 길이 두 배의 수평 준위가 놓입니다. 실선·점선·물결선은 화살표
  선 너비를, 굵은 선은 굵은 결합 너비를 따릅니다. 선은 문서의 화살표 목록에
  저장됩니다.
- **괄호와 주석** — 대괄호 / 소괄호 / 중괄호, 단검(`†`)과 이중 단검(`‡`) 주석
  객체. Select로 괄호 획 가까이를 누르고 계속 끌면 이동합니다.
- **오비탈** — s, p, sp, sp2, sp3, d, MO bonding, MO antibonding. 선택한 뒤 다시
  클릭하면 크기·회전 핸들이 나타납니다. Phase On/Off는 문서 공통 설정이며
  기존 오비탈도 바꾸고 실행 취소할 수 있습니다.
- **노트** — Return/Enter로 빈 문단을 유지합니다. 가운데·오른쪽 정렬은 가장 긴
  자연 줄의 너비를 기준으로 하며, 별도의 줄바꿈 너비를 저장하지 않고 자동 크기를
  유지합니다. 노트 배경 상자는 글자 뒤에 그려집니다.
  텍스트 편집 중에는 현재 선택 범위 또는 입력 위치에 서식을 적용하며, 편집
  밖에서는 드래그로 선택한 노트도 포함해 선택한 노트 전체에 적용합니다. 크기
  버튼은 혼합된 각 글자 크기를 증감하고, 정렬은 선택한 문단에 적용합니다.
  글꼴 메뉴를 열어도 텍스트 선택이 유지됩니다. 선택·편집 중인 노트가 없으면
  기존 노트 서식을 바꾸지 않고 해당 문서에서 새로 만들 노트의 기본 글꼴을 바꿉니다.
  이 문서 기본 글꼴 변경은 기존 화살표 라벨에도 즉시 적용됩니다.
  **Edit ▸ Note Appearance…**에서 배경 채움·색·불투명도, 테두리·색·두께, 여백,
  줄 간격을 설정합니다. 해당 문서의 기존·새 노트 모두에 적용되며 문자별 서식은
  보존하고 Undo/Redo를 지원합니다. 노트별 개별 상자 설정은 아닙니다.
- **원자 라벨** — 원소, 전하, 라디칼, 그리고 자주 쓰는 약어 라벨
  (`Me`, `Et`, `OH`, `NH2`, `SH`, `Ph`, `PPh3`, `OMe`, `Boc`, `CO2Me`, `t-Bu`, `tBu`,
  `i-Pr`, `CF3`, `OTs`, `Ts`, `OMs`, `Ms`, `OTf`, `Tf`, `Ns`, `OAc`, `Ac`).
  OH, NH2, SH는 중성이고 쐐기/해시를 포함한 단일 결합 정확히 하나로 붙어 있을 때
  Molecule Info 식별자를 지원합니다. 전하나 라디칼이 있는 원자는 원소 라벨을
  쓰세요. 이 하이드라이드 약어들은 그런 주석을 거부합니다. 다른 약어는 식별자를
  제공하지 않습니다. SMILES 삽입은 원소 라벨을 유지합니다.
- **전하 표시** — 원자 위에서 `+` / `-`를 누르면 전하가 하나씩 바뀝니다. 반대 부호의 부착 전하
  표시가 있으면 하나를 제거하고, 없으면 기존 표시와 겹치지 않게 새 표시를
  놓습니다. 단축키 한 번은 실행 취소 한 번으로 되돌립니다. 라디칼과 자유 표시는
  그대로 둡니다. 부착 표시는 원자를 선택하지 않고도 선택·이동·삭제할 수 있으며,
  Mark 도구의 미리 보기와 클릭은 같은 원자 부착 기준을 사용합니다.
  부착 표시를 드래그하거나 방향키로 옮겨도 **화학적 소유 원자는 바뀌지 않습니다**.
  Select/Move에서 표시를 선택하면 실제 소유 원자의 윤곽과 연결 점선을 보여 주며,
  멀리 떨어진 경우 호박색 안내선과 선택 상태 문구로 알려 줍니다. 이는 화학적
  유효성 검사가 아닌 배치 안내입니다. 경고는 결합 길이 하나를 넘으면 시작하며,
  긴 원자 라벨에는 여유를 더 둡니다. 안내선은 저장·복사·내보내기에 포함되지 않습니다.
  소유 원자를 바꾸려면 표시를 오른쪽 클릭 → **Reassign to atom…**에서 보라색으로
  강조되는 대상 원자를 고르고 **Reassign**을 누르세요. 처음에는 현재 소유 원자가
  선택되며, 그대로 확인하거나 취소하면 아무것도 바뀌지 않습니다. 재부착은 표시의
  위치·종류·독립 색상을 유지하면서 전하·라디칼 기여를 옮기고, 실행 취소 한 번으로
  되돌립니다. 자유 표시도 같은 대화상자에서 명시적으로 부착할 수 있습니다. 이동만으로
  자유 표시가 부착되거나 가까운 원자에 전하가 옮겨 가지는 않습니다. 그림 내보내기와
  `check-layout`은 화학적 소유권을 검사하지 않으므로, 표시가 소유 원자에서 멀리
  떨어진 그림을 공유하기 전에 해당 표시를 선택해 소유 원자를 확인하세요.
  마지막 부착 표시를 전하 단축키로 취소하거나 삭제·잘라내기·지우개·재부착으로
  없앴을 때 살아남은 고립 탄소가 보이지 않게 된다면, 탄소를 유지하고 명시적인
  `C` 라벨을 같은 실행 취소 단위로 남깁니다. 이 라벨은 저장되며 나중에 결합을
  붙여도 유지됩니다. 원자 자체가 삭제 대상이면 그대로 삭제하며, 기존 문서를
  여는 것만으로 라벨을 바꾸지는 않습니다.
- **색상(Color)** — 색을 칠하기 전에 스와치를 고르세요. 도구를 켜는 것만으로는
  색이 선택되지 않으며, 선택한 스와치는 강조됩니다. 자유 표시를 포함한 전하와
  라디칼 표시는 각각 독립적인 색을 갖습니다. 표시를 칠해도 원자색은 바뀌지 않고,
  원자색을 바꿔도 표시색은 바뀌지 않습니다. 실행 취소/다시 실행, 복사/붙여넣기,
  저장/다시 열기에서도 색을 유지합니다. 생략된 탄소를 칠해도 라벨이 나타나거나
  결합색이 바뀌지는 않습니다. 눈에 보이는 색 변화가 필요하면 표시된 라벨이나
  결합을 선택하세요.
- **격자 스냅** — **View ▸ Snap to Grid**는 시트에 결합 길이 절반 간격의 옅은
  격자를 보여 주고, 화살표와 선을 그리는 점과 끝점 핸들로 끄는 끝(곡선 화살표
  포함)을 격자에 맞춥니다. 우선순위는 기존 끝점, 그다음 `Shift`, 그다음 격자입니다.
  클릭, 그리고 격자 한 칸보다 짧은 드래그는 모두 클릭으로 봅니다. 격자는 화면에서
  너무 촘촘해 읽을 수 없을 때 숨겨지며, 문서가 아니라 창에 속합니다.
- **편집** — 끝점 핸들(화살표나 선을 선택한 뒤 다시 클릭하면 양끝에 핸들이
  보입니다. 하나를 끌면 그 끝이 움직이며 근처 끝점에 스냅됩니다. 다른 항목의
  끝점 위에 놓인 핸들은 속이 빈 대신 채워져 그려지고, 곡선 화살표는 곡률용 세
  번째 핸들을 유지합니다), 선택 / 이동, 지우개 도구(클릭 또는 드래그로 지우기;
  원자·결합 삭제로 결합이 없고 라벨이나 표시도 없는 보이지 않는 원자가 남으면 함께
  제거됩니다), 좌우·상하 뒤집기, 원근 회전, 실행 취소/다시 실행.
  앞에 있는 노트를 선택하거나 지울 때 뒤의 결합이나 보이지 않는 탄소 클릭 영역을
  건드리지 않습니다. 눈에 보이는 앞쪽 구조와 편집 핸들의 클릭 우선순위는 유지합니다.
  뒤집기는 쐐기/해시 스타일을 바꾸지 않고 좌표를 거울 반사하므로 입체중심의
  배치를 반전시킬 수 있습니다. 키랄 분자 전체를 반사하면 거울상 이성질체가
  됩니다. 뒤집은 뒤 화학적 의미를 확인하세요. 거울 반사 없이 방향만 바꾸려면
  평면 회전을 사용하세요. 평형 화살표는 길이가 다른 두 화살촉까지 정확히
  거울 반사하며, 라벨은 대응하는 화살촉과의 관계를 유지하고 읽기 쉬운 방향으로
  표시됩니다. 실행 취소/다시 실행, 복사/붙여넣기, 저장/다시 열기에서도 반사를
  유지합니다. 반사한 평형 화살표를 저장한 문서는 선택 필드 `mirrored`를 지원하는
  버전이 필요하며, 이전 버전은 잘못 그리는 대신 해당 문서를 거부합니다.
  끝점이 같은 평형 화살표가 선택되어 있으면 선택 전체를 변경하지 않고 뒤집기를
  거부합니다. 먼저 두 끝점을 떨어뜨려 주세요.
  선택하지 않은 원자를 누르고 끌면 그 원자만, 결합을
  누르고 끌면 양끝 원자만 움직입니다. 분자 전체를 끌려면 먼저 전체를 선택하세요.
  선택한 항목을 방향키로 이동하거나 정렬한 뒤 실행 취소하면 기존 원근 깊이를
  포함한 기록된 좌표를 정확히 복원합니다.
  원근 회전은 wedge/hash가 있는 해당 성분을 변경 전에 거부하므로 그 성분에는
  평면 변환을 사용하세요. Group은 연결 분자 전체를 포함합니다. 과거 부분 그룹을
  명시적으로 다시 그룹화하면 소속을 보완하지만, 파일을 열 때 자동 이행하지 않습니다.
  새 원자와 융합한 고리는 분자의 그룹에 포함됩니다. 일부를 지워도 남은 구성원은
  그룹을 유지하며, Undo/Redo는 그림과 그룹 소속을 함께 복원합니다. 서로 다른
  그룹을 연결하려면 두 구조를 선택해 **Edit ▸ Group**으로 묶은 뒤 다시 연결하세요.
  새 그룹을 만들 때는 객체가 두 개 이상 필요하며 연결 분자는 하나로 셉니다. Arrange Scheme
  블록을 만들 때는 캡션이나 다른 객체도 함께 선택하세요.
  회전과 뒤집기는 하나의 선택/그룹 중심을 공유합니다. 노트, 이미지, 도형과 TS 괄호는
  그 중심 주위를 이동하되 내용은 똑바로, 사각형은 축에 평행하게 유지됩니다.
  Select에서 선이나 화살표의 획 가까이를 누르면 선택되고, 계속 끌면 같은 동작으로
  이동합니다. 클릭 여유는 줌과 무관하게 화면 기준으로 재며, 곡선의 안쪽은 채워진
  클릭 대상으로 보지 않습니다. 드래그가 시작되기 전 시스템 드래그 문턱 아래의
  포인터 이동은 그림과 실행 취소/다시 실행 스택을 바꾸지 않습니다. 이미 선택된
  획을 클릭하면 끝점 핸들이 켜지고 꺼집니다.
- **데스크톱 메뉴** — 표준 File / Edit / View 메뉴. 시트 크기와 방향을 위한
  **Canvas Size** 대화상자를 포함합니다. 변경은 Undo/Redo가 가능하며 시트 밖 객체는
  삭제하거나 시트 안에 맞추지 않고 스크롤로 접근할 수 있습니다. 시트 전용 출력과
  검사의 경계는 여전히 실제 시트를 따릅니다.
  Select/Move로 끌 때 미리보기는 시트 밖에서도 포인터를 따라갑니다. 그리기와
  포인터 아래 원자/결합 편집은 시트 안으로 제한하며, 막힌 시도에는 내용을 시트
  안으로 옮겨 편집하라는 상태 메시지를 표시합니다.
- **키보드 단축키** — 도구 선택과 포인터 아래 원자/결합 편집
  ([키보드 단축키](#키보드-단축키) 참조).
  새 창은 캔버스에 포커스를 둡니다. 노트를 편집 중이 아니라면 `Tab`/`Shift+Tab`은
  창의 컨트롤을 순회하고 캔버스로 돌아옵니다. 스타일이 적용된 문맥/상태 표시줄
  버튼은 포커스 테두리를 표시합니다. 줌 백분율 버튼에 포커스가 있을 때 `Space`는
  100%로 초기화하고 `Enter`는 Set Zoom을 엽니다. 노트 편집 중에는 기존 Tab 입력
  동작이 유지됩니다.

## `.chemvas` 파일 형식

File ▸ Save / Open은 `.chemvas` 파일을 다룹니다. 분자 모델, 주석, 화살표, 괄호
주석, 설정을 담는 JSON 기반 형식입니다.

```json
{ "type": "chemvas", "version": 7, "state": { /* ... */ } }
```

버전 7이 유일하게 지원되는 문서 계약입니다. 여기에 유계 반응 전 복합체 후보,
정확한 XYZ 출처, 명시적 종점 검토 선택을 담은 선택적 Calculation Plan v2를 실을 수
있습니다. 이전 문서 버전과 Calculation Plan v1 페이로드는 거부됩니다.

문서를 열거나 구조를 삽입할 때 겹친 원자를 그대로 보존하므로, 캔버스에서 옮기거나
편집하여 배치를 고칠 수 있습니다. 외부에서 바뀐 파일이나 저장 기준을 확인할 수
없는 복구 문서의 원본을 덮어쓰려 하면 먼저 확인합니다. 두 버전을 보존하려면 No를
고른 뒤 Save As를 사용하세요. 관측된 변경을 감지하는 기능이며 프로세스 간 편집
잠금은 아닙니다.

Chemvas 그림은 `.chemvas` 접미사를 써야 합니다. 데스크톱 시작 인자, OS 파일 열기
이벤트, **File ▸ Open**, **Open Recent**, 깨끗한 세션 재열기는 모두 `.json` 그림
경로를 거부하거나 무시합니다. **Save**와 **Save As**는 그림을 `.chemvas`로만
게시합니다. 헤드리스 명령이 쓰는 JSON 요청, 패치, 보고서, 기계 산출물 파일은
별도의 프로토콜이며 영향받지 않습니다.

## 자동 저장과 복구

Chemvas는 열린 모든 문서를 몇 초마다 사용자별 앱 데이터 폴더에 스냅숏으로
저장합니다. 사용자의 파일 옆에는 아무것도 쓰지 않습니다. 앱이 강제 종료되거나
충돌하면 다음 실행 때 그 문서들을 복원하며(저장하지 않은 것은 `●`와 상태 표시줄
안내로 표시), 정상 종료 후에는 열려 있던 파일을 그대로 다시 엽니다. 스냅숏은
세션이 복원되거나 정상 종료되면 정리됩니다. 지원하지 않는 그림 경로에 대한 오래된
최근 파일·깨끗한 세션 항목은 무시됩니다. 현재의 내부 충돌 자동 저장은 그림
데이터를 여전히 복구할 수 있지만, 지원하지 않는 원래 경로는 버려지고 복구된
캔버스는 저장되지 않은 문서로 경로 없이 열립니다.

자동 저장은 온전한 복구 스냅숏을 캡처 중 경고가 보고된 스냅숏으로 바꾸지
않습니다. 마지막 정상 스냅숏을 유지하고 대신 상태 표시줄에 경고를 계속 표시하며,
이후 자동 저장이 경고 없이 성공해야 경고가 사라집니다.

변경 없는 주기에는 디스크 쓰기를 생략합니다. 저장 후 변경하지 않은 문서는
스냅숏 저장소의 두 번째 내용 해시 계산도 생략하지만, 각 캔버스의 상태 수집과
변경 확인은 계속 수행합니다. 큰 삽입 이미지가 있으면 유휴 주기나 편집이 여전히
느릴 수 있으며, 문서 크기와 무관한 변경 감지기는 아닙니다.

중단된 것으로 확인된 세션에서 읽을 수 없는 미저장 스냅숏과 메타데이터를 잃은
스냅숏 파일은 경고와 함께 보존하며 조용히 삭제하지 않습니다. 소유권을 확인할 수
없는 손상 세션은 경고 없이 보존될 수 있습니다. 같은 파일의 미저장 복구본이 여럿이면 모두 보존하고,
추가 버전은 원본 경로에 연결되지 않은 미저장 복구 사본으로 엽니다.

Quit는 모든 창의 Save / Discard / Cancel 선택을 마친 뒤 창을 닫으며,
버린 초안을 다시 직렬화하지 않고 최종 저장 파일 목록을 함께 보존합니다.
저장하지 않고 버린 이름 없는 그림은 다시 열지 않습니다. 취소하거나 저장에 실패하면
창을 열린 채로 둡니다. 복구된 이름 없는 그림에는 서로 다른 이름을 붙이고,
File Open과 Open Recent는 가능하면 기존의 빈 그림을 재사용합니다.
내용이 있는 가져온 그림은 빈 창으로 취급하지 않습니다. Quit 도중 운영체제에서
들어온 파일 열기 요청은 상태 메시지와 함께 거절하며, 종료를 취소하거나 앱을
다시 실행한 뒤 열어야 합니다. 자동으로 다시 열도록 대기열에 넣지는 않습니다.

쓰기 가능한 앱 데이터 위치가 바뀌면 알려진 다른 저장 위치에도 중단된 세션의
복구 스냅숏이 있는지 확인합니다. 계속 표시되는 경고로 위치와 복구 방법을
안내하며, 자동으로 합치거나 삭제하지 않습니다. `doc-*.json` 스냅숏을 새
`.chemvas` 파일로 복사한 뒤 그 사본을 열고, 원래 복구 파일은 그대로 보관하세요.

저장하지 않은 탭은 `●` 표시가 붙고, File 메뉴에는 **Open Recent** 목록이 있으며,
이미 열린 파일을 다시 열면 복제하지 않고 그 창으로 전환합니다.

## 그림 출력

물리적 크기 프리셋(결합 길이 기준 또는 84 / 174 mm 단 맞춤)이 있는 일반 SVG /
PDF / PNG / TIFF. 줌과 무관합니다. 벡터 출력에서 원자와 화살표 라벨은 윤곽선으로
바뀌어 글리프 모양과 위·아래 첨자 위치가 보존됩니다. 다른 텍스트 항목은 각자의
렌더링 동작을 유지합니다. 출력 설정과 버전별 가용성은
[예제](FIRST_SCHEME.ko.md#4-그림-출력하기)를 보세요.

TIFF는 무손실 LZW 압축을 사용하며 픽셀, RGBA 투명도와 지정한 DPI를 보존합니다.
흰 배경 출력은 불투명한 알파 채널을 그대로 유지합니다.
원자 라벨은 편집·클릭 영역을 제외하고 실제 글리프 범위에 맞춰 출력합니다.
노트와 화살표 라벨은 기존 배치 상자 범위를 유지하며, 리치 텍스트 장식과 자동
목록 기호를 잘라내지 않습니다.

그림 출력의 기본값은 Chemvas 원본 메타데이터가 없는 일반 SVG입니다. SVG가 원래
문서 페이로드를 담아 Chemvas로 되돌아올 수 있게 하려면 **Editable Chemvas SVG**를
고르세요. 전체 문서의 editable SVG는 Save와 같은 계산 계획 초안 검사를 거칩니다.
낡은 참조를 제외하거나 유효하지 않은 계획·검토 데이터를 남길 때 먼저 확인하며,
No를 누르면 출력 파일을 바꾸지 않습니다. 초안 저장이 계산 승인을 뜻하지는 않습니다.
**Selection** 범위의 편집 데이터는 선택한 객체, 완전히 복사된 그룹과 문서 설정을
담습니다. Calculation Plan과 선택하지 않은 객체는 포함하지 않으며 원래 용지 설정의
새 그림으로 열립니다. 모든 객체를 선택했더라도 출력 창에 이 차이가 안내됩니다.
다시 열 때는 내장된 그림 데이터를 복원합니다. 다른 앱에서 SVG의 보이는 벡터만
수정해도 내장된 Chemvas 그림 데이터가 바뀌지는 않습니다.

GUI의 모든 출력 프리셋은 `render-document`와 같은 크기 제한을 적용합니다.
한 변은 최대 14,400포인트이며, PNG/TIFF는 한 변 최대 10,000픽셀·전체
2,500만 픽셀입니다. 한도를 넘으면 그리기 전에 거절하고 기존 출력 파일을
그대로 둡니다. PDF는 가까운 표준 용지로 맞추지 않고 정수 포인트 단위의
사용자 크기를 쓰며, 그림의 종횡비를 유지해 그 페이지 안에 배치합니다.

## 화학 입출력

RDKit은 선택적 백엔드이며 Chemvas는 RDKit 없이도 동작합니다. *(RDKit)* 표시가 있는
기능은 `pip install "chemvas[rdkit]"`이 필요합니다.

![화학 입출력: molfile 열기, Molecule Info, MOL과 3D XYZ 내보내기](images/walkthrough-chemistry.gif)

### SMILES 가져오기 *(RDKit)*

**Ring**을 고르고 옵션 바에 SMILES 문자열을 입력한 뒤 **Insert**를 누릅니다. 커서
아래에서 미리 보고 클릭해 캔버스에 놓습니다. 캔버스에서 `Ts`와 `Ac`는 토실과
아세틸 약어이므로, 테네신이나 악티늄을 요구하는 SMILES는 약어로 그려지는 대신
거부됩니다.

절대 사면체 입체화학(`@` / `@@`)은 쐐기/해시 결합으로 그려집니다. 지정된 이중 결합
입체화학(`/` / `\`), 사면체가 아닌 입체화학, 상대 또는 라세미 CXSMILES 입체
그룹은 캔버스가 보존할 수 없어 거부됩니다. 동위원소 라벨도 지원하지 않습니다.

단일, 이중, 삼중 결합을 지원하며 RDKit이 그 결합 차수로 케쿨레화할 수 있는 방향족
구조도 포함합니다. 배위, 미지정, 사중 결합 같은 다른 결합 유형은 근사하지 않고
거부합니다. 케쿨레화로 표현할 수 없는 방향족 입력도 거부됩니다.

명시적으로 그린 수소는 정상 원자가에 포함되며, 나머지 암시적 수소를 모두 없애지
않습니다. 예를 들어 표시 없는 O–H는 물로 완성되며, 하이드록실 라디칼을 의도하면
라디칼 표시를 붙이세요. 약어는 지원되는 단일 결합으로 붙여야 합니다. 점선과 이중
점선 접촉은 그림에서 계속 편집할 수 있지만, 이를 포함한 선택의 화학 식별자,
MOL/XYZ, 3D 및 계산 변환은 공유결합으로 취급하지 않고 명시적으로 거부합니다.

### MOL 교환

MDL Molfile(`.mol`, V2000)을 새 문서로 열고 선택한 구조를 `.mol`로 내보냅니다.
가져오기와 일반 원소 내보내기는 RDKit이 필요 없고, 약어 라벨은 선택적 RDKit
확장이 필요합니다. 캔버스에서 `Ts`와 `Ac`는 테네신과 악티늄이 아니라 토실과
아세틸 약어이므로, 두 기호 중 하나를 원소로 쓰는 molfile은 가져올 때 거부됩니다.
속성 레코드는 `M  CHG` / `M  RAD`로, 쐐기/해시 입체는 단일 결합으로, 개수 줄의
키랄 플래그는 0으로 제한됩니다. 단일항 `M  RAD` 코드 1은 주석 모델이 스핀 다중도를
보존할 수 있을 때까지 거부됩니다.

### Molecule Info 창 *(RDKit)*

**View ▸ Molecule Info**는 3D 미리보기(드래그로 회전, 스크롤로 줌), 분자식과
분자량, 현재 선택의 정규 SMILES·InChI·InChIKey 원클릭 복사를 갖춘 별도 창을
엽니다. `Export 3D XYZ` 버튼은 선택한 분자를 내보냅니다. 식별자는 미리보기와 같은
변환을 써서 그려진 쐐기/해시 입체화학을 보존합니다. 약어 라벨에는 식별자를 쓸 수
없지만, 미리보기와 3D 내보내기는 지원되는 약어를 여전히 확장할 수 있습니다.
초기 화면은 깊이 효과를 포함한 원자의 투영 크기에 맞춰집니다. 회전하거나
확대해도 분자는 전용 표시 영역 안에서만 그려져 제목·분자식·분자량을 가리지
않습니다. 확대 시 분자의 일부는 이 영역의 가장자리에서 잘릴 수 있습니다.

### 2D→3D `.xyz` 내보내기 *(RDKit)*

현재 분자 또는 원자/결합 선택을 3D 좌표로 변환합니다.

- 내보내기 범위는 현재 화학 그래프 또는 현재 원자/결합 선택입니다. 화살표, 괄호
  주석, 자유 텍스트는 `.xyz`에 **포함되지 않습니다**.
- `+`/`-`/라디칼 표시는 형식 전하 / 라디칼 전자가 되고, 단일 결합의 쐐기/해시는
  RDKit 입체화학 힌트가 됩니다.
- 약어 라벨은 명시적 조각으로 확장됩니다(예: `OTs` → 전체
  `-O-S(=O)(=O)-C6H4-CH3` 토실레이트). 각 약어는 단일 결합 하나로 붙으며, `Ns`는
  파라(4-나이트로벤젠설포닐) 이성질체입니다. 탄소에 붙은 `PPh3`는 정확히 하나의
  보통 공유 단일 결합을 통해서만 허용되며 포스포늄 `C-[P+](Ph)3`로 확장됩니다.
  단독, 비탄소, 다중, 비단일, 스타일이 있는 결합, 또는 전하/라디칼 주석이 명시된
  경우는 실패로 닫힙니다.
- 지원하지 않는 라벨, 잘못 연결된 약어, 잘못된 쐐기/해시 사용은 추측하지 않고
  명시적 오류 메시지로 실패합니다.
- `.xyz`는 원소 기호와 3D 좌표만 저장합니다. 결합 차수, 입체화학, 반응 의미의 완전한
  왕복 형식이 **아닙니다**.

## 키보드 단축키

자유 텍스트 노트를 편집하는 동안 드래그로 텍스트를 선택하고, 더블클릭으로 단어를
선택하고, Shift-클릭으로 선택을 늘립니다. 서식 컨트롤은 편집기를 활성 상태로
유지합니다. 다른 도구를 고르면 노트가 확정되고 키보드 입력이 그림으로 돌아갑니다.
편집기 안의 실행 취소는 현재 편집 세션에 적용되고, 편집기를 떠난 뒤의 문서 실행
취소는 확정된 편집을 되돌립니다. 저장되지 않음 표시는 노트가 포커스를 잃기 전의
입력, 서식, 텍스트 실행 취소도 추적합니다. `Esc`를 누르면 텍스트를 버리지 않고
노트를 확정하며 Select로 돌아갑니다. 노트의 간격, 탭, 빈 문단은 저장/재열기나
확정된 편집의 실행 취소/다시 실행에서 유지됩니다.

Select에서 노트와 도형은 화살표처럼 첫 드래그로 옮길 수 있습니다. 선택 밖의 빈
캔버스를 클릭하면 선택된 노트를 포함해 선택이 해제됩니다. 복사/붙여넣기는 완전한
그룹을 독립된 복사본으로 보존하며, 실행 취소 한 번으로 붙여 넣은 객체와 그룹이
함께 제거됩니다. 프로그램 선택이 제공한 부분 그룹은 그룹 없이 복사됩니다.

캔버스의 빈 곳에서 도구를 고르거나, 원자나 결합 위에 포인터를 올리고 아래 키로
편집합니다.

- **빈 캔버스(도구 단축키):** Select/Marquee `Space`, Bond `X`, Atom `A`,
  Text `T`, Arrow `E`, Benzene `J`, Brackets `Shift+T`, Orbitals `Shift+G`,
  Charge / Radical(Mark) `Shift+E`, Perspective `Alt+D`
- **원자 단축키(원자 위에서):** [원소/약어 라벨 대응표](#원자-라벨-단축키-대응표), 전하 `+`/`-`,
  라벨 편집 `Enter`, 가지 내기 `0/1/2/3/a/4/5/6/7/8/9/z/v/u` (`9` = gem-다이메틸)
- **결합 단축키(결합 위에서):** 단일 `1`, 이중 `2`, 삼중 `3`,
  굵게 `b`/`Shift+B`, 쐐기 `w`, 해시 `h`/`Shift+H`, 점선 `d`/`Shift+D`,
  이중 결합 위치 `l`/`c`/`r`, 벤젠 융합 `a`,
  고리 융합 `4/5/6/7/8`, 의자 융합 `9/0`
- **객체:** 좌우 뒤집기 `Ctrl+Shift+H`, 상하 뒤집기 `Ctrl+Shift+V`,
  둘 다 좌표를 거울 반사하여 입체중심을 반전시킬 수 있음(위 편집 설명 참조);
  선택 회전 `Alt+Up/Down`(15°)과 `Alt+Left/Right`(1°),
  선택 밀기 `Shift+Arrows`(10 pt); **Edit ▸ Align**(left, center, right, top,
  middle, bottom)과 **Edit ▸ Distribute**(horizontally, vertically)는 선택한
  구조와 객체를 하나의 단위로 배치합니다. 분자는 일부만 선택돼도 통째로 움직이고,
  그룹은 하나로 움직입니다.
- **보기:** 실제 크기 `F5`, 창에 맞춤 `F6`, 확대 `F7`, 축소 `F8`
- **파일 / 편집:** 저장 / 열기 / 실행 취소 / 다시 실행(플랫폼 기본), `Ctrl+A`(전체
  선택, Select 도구로 전환), `Ctrl+C`(선택 복사 — PNG와 SVG/PDF 벡터 클립보드
  형식), `Ctrl+X`(선택 잘라내기), `Ctrl+V`(복사한 선택 붙여넣기),
  `Ctrl+G` / `Ctrl+Shift+G`(선택 그룹 / 그룹 해제),
  `Delete`/`Backspace`(선택 삭제, 또는 포인터 아래 원자/결합 편집·삭제),
  `Esc`(템플릿 / SMILES 삽입 취소; 그 외에는 진행 중인 동작을 취소하고 Select로
  복귀, 또는 노트 편집을 확정하고 나감)

### 원자 라벨 단축키 대응표

포인터 아래 원자의 라벨을 바꿉니다. 대문자는 `Shift`와 해당 키를 함께 누르는
것입니다. 라벨을 그릴 수 있다는 사실이 화학 변환 지원을 보장하지는 않습니다.

| 키 | 라벨 | Shift와 함께 → 라벨 |
| --- | --- | --- |
| `a` | — (벤젠 가지 내기) | `Ac` |
| `b` | `Br` | `B` |
| `c` | `C` | `Cl` |
| `d` | `D` | — |
| `e` | `Et` | `CO2Me` |
| `f` | `F` | `CF3` |
| `h` | `H` | `Cbz` |
| `i` | `I` | — |
| `k` | `SO2` | `t-Bu` |
| `l` | `Cl` | `Li` |
| `m` | `Me` | `MgBr` |
| `n` | `N` | `NO2` |
| `o` | `O` | `OMe` |
| `p` | `P` | `Ph` |
| `q` | `O` | `Fmoc` |
| `r` | `R` | — |
| `s` | `S` | `Si` |
| `w` | `N` | — |
| `x` | `X` | — |
| `y` | — | `Boc` |
| `z` | — (가지 내기) | `N3` |

`NO2`, `N3`, `MgBr`, `Fmoc`, `Cbz`, `SO2`, `R`, `X`, `D`는 화학 변환이 지원되지
않는 그리기 라벨이며 Molecule Info 식별자나 3D 내보내기를 제공하지 않습니다.
특히 `D`는 동위원소 지원을 구현한 것이 아닙니다. 다른 약어에도
[화학 입출력](#화학-입출력)에 설명한 결합 연결과 변환 제한이 적용됩니다.

### 단축키 호환성

이 바인딩의 상당수는 ChemDraw와 같아서 익숙한 그리기 습관을 그대로 가져올 수
있습니다. 위 목록이 Chemvas가 지원하는 키를 정의하며, 완전한 단축키나 파일 형식
호환을 뜻하지는 않습니다.

## 로드맵 / 아직 지원하지 않는 것

버그가 아니라 알려진 공백입니다. 기여를 환영합니다.

- **SDF(다중 분자) 교환:** 가져오기와 내보내기. 단일 분자 `.mol` 가져오기/내보내기,
  SMILES 내보내기("copy as SMILES"), InChI / InChIKey는 이미 들어왔습니다.
- **배포:** 단일 파일 데스크톱 바이너리(Chemvas는 이미 PyPI에 있습니다 —
  `pip install chemvas`).
- **다중 분자 / 반응식 3D 내보내기**와 더 풍부한 템플릿 라이브러리.
- **당분간 의도적으로 범위 밖:** 인쇄(대신 PDF로 출력), 영구 환경설정(모든 문서는
  ACS 1996 기본값에서 시작), 일반 외부 텍스트/구조 클립보드 가져오기, 드래그 앤
  드롭 파일 열기. 외부 클립보드 이미지는 이미 붙여넣을 수 있습니다.
  [이미지 객체](IMAGE_OBJECTS.ko.md)를 보세요.
