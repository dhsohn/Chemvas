# 브라우저 어댑터

[English](WEB_ADAPTER.md)

브라우저 어댑터는 독립적인 웹 제품 출시가 아닌 향후 Leaf 통합을 목표로 개발 중인
실험적 인터페이스이다. 저장소 소스 체크아웃에서만 실행할 수 있으며, 배포용 wheel 및
sdist 패키지에는 웹 어댑터 모듈과 에셋이 포함되지 않는다.

## 실행 (소스 체크아웃 전용)

```bash
python -m pip install -e .
chemvas --ui web
chemvas --ui qt
```

`make check` 이후 macOS/Linux는 `.venv/bin/chemvas`, Windows는
`.venv/Scripts/chemvas.exe`를 사용한다. Python 3.12+가 필요하다.
패키지 설치 환경에서 `chemvas --ui web`을 실행하면 소스 체크아웃이 필요하다는
오류 메시지가 출력된다.
`chemvas --ui web --no-browser`는 실행 URL을 출력한다. 터미널을 유지하고
Ctrl+C로 서버를 종료한다. URL의 세션 인증 정보는 로컬에서만 사용한다.
프런트엔드 빌드·CDN·Node 런타임은 필요하지 않다. 브라우저 서버는 Qt를 import하지
않으며, 개발 환경은 데스크톱 앱을 위해 Qt를 제공한다.
File > Export Figure만 데스크톱의 Qt 그림 내보내기를 짧게 실행되는 별도 프로세스에서
실행하므로 그 Qt 설치가 필요하다.

## 연결된 기존 구현

- 도구 순서·이름·툴팁·결합 옵션·상태 안내는 기존 `main_window_config`에서 읽는다.
  SVG 아이콘, 색상, 버튼 크기와 ACS1996 그리기 기본값도 양쪽이 공유한다.
  옵션바는 Qt의 흰색 선택 박스·옅은 테두리·그룹 간격을 사용한다.
- 결합 생성은 `StructureBondBuildService`와 `StructureBuildCommitter`가 실행한다.
  결합 입력은 장면 좌표를 보내고 기존 원자 우선 판정과 공통 반경을 쓴다.
  결합 위에 놓으면 기존 끝 원자 스냅 규칙을 적용하며 각도 간격은
  `CanvasToolSettingsState`에서 읽는다. 기존 원자·결합 재사용은 원래 생성기가
  담당한다. 웹은 손을 놓을 때 확정하고 Qt는 결합을 누르는 즉시 스타일을 바꾼다.
- 벤젠 삽입은 `StructureBenzeneBuildService`와 같은 커미터를 호출하고, Ring 페이지의
  다른 템플릿은 데스크톱의 템플릿 계획, `TemplateGeometryResolverService`,
  `commit_template_ring`을 그대로 쓴다.
  클릭 대상은 Qt의 원자·결합 거리 우선순위와 삽입 허용 반경으로 판정하고,
  원자 선택 원도 기존 반경을 쓴다. 붙이기, 융합, 원자 합치기, 결합 차수와
  고리 기록을 그대로 사용한다. 라벨 클릭 영역은 측정한 글자 외곽 사각형이다.
  짧은 기호에만 기존 Qt 판정 함수를 통해 선택 원을 붙인다.
  글꼴 측정에 따른 작은 경계 차이는 남는다.
  삭제는 항목 수에 관계없이 같은 선택 삭제 요청으로 기존 삭제 계획을 실행한다.
- 굵은 결합(Bold)은 기존 `BondGraphicsDrawService`의 다각형을 표시한다.
  이중·삼중 결합의 차수, 고리 방향과 인접 굵은 결합 접합 계산을 그대로 쓴다.
- 점선 결합(Dotted)의 점 위치·반지름·접합부 간격은 기존
  `BondLineGeometryService.dotted_bond_dots`를 사용한다. 이중 결합에 적용할 때도
  원래 차수와 안쪽/바깥쪽 규칙을 유지한다. SVG는 전달받은 원만 표시한다.
- 원자 라벨의 방향·별칭 기준점·아래첨자·수소 세로 배치는 기존 함수를 쓴다.
  브라우저는 글자 폭과 줄 높이를 측정해 Python 배치 함수에 전달하고,
  계산된 글자 위치와 Qt의 96 DPI 규칙으로 환산한 정수 픽셀 크기로 표시한다.
  세션마다 크기를 제한한 글꼴 측정값과 글자 외곽선 한 세트를 보관한다.
  문서·Undo/Redo에는 넣지 않으며, 편집·미리보기·이력 복원 시 기존 배치 함수와
  결합 렌더러가 바로 사용한다. 이미 측정한 글자는 응답·렌더링 한 번으로 끝난다.
  새 글자가 나타날 때만 응답의 리비전에 맞춰 측정값을 보내며, 문서를 다시 보내거나
  확정된 편집을 재실행하지 않는다. 미리보기도 세션·리비전·편집 정보만 전송한다.
  잘못되거나 오래된 측정값은 문서·이력·기존 측정값을 바꾸지 않는다.
  측정 세트를 교체하면 이전 세트는 버린다. 볼록 외곽선·여백 반경·평행선 영역의
  교차 계산은 Qt와 공유하며 고정 간격 자르기와 흰색 라벨 덧칠은 제거했다.
  브라우저는 제한된 크기의 캔버스에서 최대 8배 해상도로 글자를 측정한다.
  절반 이상 덮인 픽셀로 윤곽을 잡고 글꼴 엔진의 실제 경계 안으로 제한해,
  흐릿한 외곽 픽셀이 글자 크기를 늘리지 않도록 한다.
  원형 여백은 64각형으로 근사한다. 글꼴 엔진과 측정 오차로 작은 차이는 남을 수
  있으며 모든 플랫폼의 픽셀이 동일하다는 의미는 아니다.
- 저장된 전하·라디칼 표시는 원본 원자 귀속 좌표, 원·점 크기와 텍스트 배치를
  공유하여 웹에서도 표시한다. 사용자 지정 색과 일반 문구의 줄바꿈을 유지하며,
  글꼴 엔진의 반올림 차이는 남을 수 있다. 표시 생성·이동·귀속 변경·전하
  단축키는 데스크톱과 같은 서비스를 거친다.
- 괄호와 대거 기호는 데스크톱의 획 명령과 글리프 배치를 쓰고, 경계는 데스크톱이
  채우는 외곽선을 따른다. 대거 경계는 브라우저가 측정한 글리프 잉크에서 얻는다.
- SVG 결합 선은 기존 `BondGeometryPlanService`, `BondLineGeometryService`,
  `BondRingDoubleGeometryService`의 결과를 표시한다. 고리 중심 선택도 공유한다.
  양쪽 모두 현재 문서의 고리 순서를 캐시된 그래프 고리보다 우선한다.
- 화살표·선 경로는 기존 Qt 계산을 `line_geometry`로 옮겨 함께 쓴다.
  Qt는 경로 명령을 `QPainterPath`로, 웹은 같은 명령을 SVG로 표시한다.
  19종의 굵기·점선 간격·끝 모양과 평형 반전·길이 차이·곡선 제어점을 유지한다.
  문서의 화살표 경로는 50만 점까지 처리한다.
  라벨 없는 화살표·선은 기존 이동 컨트롤러와 삭제 계획기로 선택·드래그·전체 선택·삭제·Undo/Redo를 처리한다. 화살표 생성은 기존 끝점 스냅·기본 곡선·Shift 원호 반전을 사용하고, 기존 아이콘과 More arrows 구성을 연결했다. 선 4종은 기존 끝점·Shift 규칙과 빈 곳 클릭 시 길이를 사용한다. 화살표 프리셋과 굵기·머리 크기 슬라이더도 기존 값과 제한을 공유한다.
  선택된 화살표를 다시 클릭하면 끝점 핸들을 여닫고, 곡선은 중앙 핸들도 표시한다.
  최소 길이·끝점 이동 시 곡선 유지·중앙점 제한은 기존 공용 기하 계산을 호출한다.
  다른 끝점에 스냅된 핸들은 채워지고, 핸들 크기는 배율과 무관하게 유지된다.
  미리보기는 마지막 유효 끝점을 유지하며, 놓을 때 한 번만 기록하고 Escape로 취소한다.
  화살표 라벨은 기존 구문·배치 계산을 사용하며 더블 클릭으로 위·아래 라벨을 편집한다.
- Enter·Delete·원자/성장 단축키도 현재 라벨의 실제 클릭 영역을 먼저 확인한다.
  긴 라벨의 끝에서도 같은 원자를 찾고, 직접 닿지 않으면 기존 거리 판정을 쓴다.
  선택 강조 표시는 클릭 영역을 넓히지 않는다.
- 원자 입력은 Qt의 호버 대상을 먼저 고르고, 이후 가까운 결합 끝점과 원자를
  찾는다. 라벨 직접 클릭의 우선순위도 유지하며 SVG 결합 ID로 원자를 고르지 않는다.
- 원자 도구는 기존 `AtomLabelService`와 `AtomLabelMergeService`를 호출한다.
  탄소 표시, 겹친 원자와 중복 결합의 병합, 비탄소 기호 숨김 거부 규칙을 공유한다.
  입력창 속성과 클릭 대상·입력 계획도 Qt 소유자에서 가져온다.
- 선택 항목 이동은 기존 `CanvasMoveController`를 호출한다. 결합 끝점은 기존
  선택 확장 함수로 중복 없이 계산하고, 고리 채움은 기존 polygon 갱신기로 맞춘다.
  드래그 미리보기와 확정 편집은 같은 서버 경로를 쓴다.
- Undo/Redo는 기존 `CanvasHistoryService`와 `CanvasHistoryState`가 담당한다.
  서버가 기존 연산으로 임시 후보를 만들고 검증·기록한 뒤 승인된 상태를 전달한다.
  기록에는 문서만 저장하고 Undo/Redo 때 기존 렌더러로 화면을 다시 계산한다.
  재계산 실패 시 기존 이력 트랜잭션이 문서와 기록을 유지한다.
  JavaScript는 승인된 상태를 표시한다. 응답이 끊기면 편집을 재전송하지 않고
  서버의 현재 문서를 읽는다. 읽기도 실패하면 다음 동작은 재연결만 수행하고,
  갱신된 문서를 확인한 뒤 다시 편집하도록 안내한다.

A로 원자 도구를 선택한다. 상단에 기호를 입력한 뒤 클릭하면 해당 기호를 적용하고,
입력창이 비어 있으면 기존 원자 기호를 담은 대화상자를 연다. 취소는 문서를 바꾸지 않는다.
X로 결합을 그리고 J로 벤젠을 놓거나 기존 원자·결합에 붙인다.
결합 위에서 1/2/3, b/w/h/d, Shift+B/H/D, l/c/r을 누르면 기존 Qt 결합 스타일 규칙을 적용한다.
빈 곳에서는 이 키가 그리기 옵션을 바꾸지 않는다. 원자 위에서는 기존 라벨 문자와
0–9/z/v/u 성장 단축키를 사용한다. 소문자 a는 원자에 벤젠을 붙이거나 결합에 융합한다.
결합 위의 4–8은 일반 고리, 9/0은 두 방향의 의자형 고리를 융합한다.
호버 동작을 먼저 처리하므로 A는 해당 구조가 키를 소비하지 않을 때만 원자 도구를 선택한다.
X는 빈 곳에서 결합 도구를 Single로 되돌리고 원자 위에서는 X 라벨을 적용한다.
전하(+/−)는 미연결 안내를 표시한다. 원자 위의 Enter는 현재 도구 기호와 무관하게
기존 라벨 대화상자를 연다. 빈 입력을 확인하면 암시적 탄소로 되돌리고 취소는 문서와
이력을 바꾸지 않는다. 결합 위나 빈 곳의 Enter는 아무것도 바꾸지 않는다.
툴바를 마우스로 눌러도 Qt의 NoFocus처럼 기존 포커스를 유지한다.
키보드로 버튼이나 메뉴 제목에 포커스를 주면 Enter·Space는 그 컨트롤을 실행한다.
캔버스에서는 Space로 선택하고 드래그해 이동한다. Shift+클릭으로 선택을 추가·해제하고,
⌘/Ctrl+A로 전체 구조를 선택한다. Delete는 선택 전체를 한 명령으로 삭제한다.
선택이 없으면 Delete/Backspace는 결합된 원자의 보이는 라벨을 먼저 암시적 탄소로
되돌리고, 그 외에는 포인터 아래 원자나 결합을 삭제한다. 고립된 라벨 원자는 즉시 삭제한다.
지우개는 클릭한 항목을 삭제한다. Escape는 미리보기를 취소하고 Select로 돌아간다. 도구 전환·포커스 이탈도 미리보기를 취소한다. 결합을 클릭하면 선택한 스타일을
적용하고, 결합 도구의 짧은 클릭은 기존 기본 방향으로 결합을 만든다.
제스처 하나를 Undo 한 번으로 취소한다.
일반 휠은 스크롤하고 macOS는 Cmd+휠, 다른 플랫폼은 Ctrl+휠로 포인터 중심 확대를 한다.
브라우저의 Control·핀치 확대도 유지한다. 배율 제한(20–500%)과
버튼 간격은 데스크톱 선언을 공유한다. 브라우저 픽셀 입력은 Qt의 각도/픽셀 비율로
변환하고 줄·페이지 입력은 글줄 높이·화면 크기를 사용한다. 브라우저는 Qt 각도 입력을
제공하지 않으므로 실제 장치의 휠 감도는 다를 수 있다.
F5–F8로 확대를 조절한다.

File → Open으로 `.chemvas`를 열고 Save로 사본을 다운로드한다.
버전 7–9의 문서 버전과 데이터를 유지하며 Qt에서도 사본을 열 수 있다.
다운로드 시작만으로 디스크 저장 완료를 확인할 수 없어 변경 표시와 종료 경고는
유지하며, Save 다운로드가 변경 표시를 지우거나 복구 드래프트를 삭제하지 않는다.

자동 복구 드래프트는 데스크톱 Qt 복구와 별개로 미저장 그림을 보호한다. OS
프로세스 잠금으로 한 번에 하나의 실행 중인 서버만 드래프트 폴더를 소유하며,
동시에 실행된 두 번째 서버는 복구 기능이 꺼진 상태로 실행되고 사용자에게 이를
알린다. 미저장 문서마다 고유한 무작위 드래프트 식별자를 부여한다. 승인된 변경마다
문서 이름, 저장 시각, `.chemvas` 페이로드를 담은 드래프트 봉투에 완전한 그림을
원자적으로 기록하며, 실행 토큰, origin, 세션 식별자는 저장하지 않는다. 파일은
로컬 사용자 애플리케이션 저장소(macOS: `~/Library/Application
Support/Chemvas/browser-drafts`, Windows: `%LOCALAPPDATA%/Chemvas/browser-drafts` 또는
`~/AppData/Local/Chemvas/browser-drafts`, Linux: `$XDG_DATA_HOME/Chemvas/browser-drafts`
절대경로 또는 `~/.local/share/Chemvas/browser-drafts`), 또는 CLI 실행 시 `--drafts-dir`로
지정한 폴더에 암호화되지 않은 파일로 저장된다. 서버가 다른 루프백 포트로 재시작되거나
브라우저를 새로 고쳐도 드래프트는 유지된다.

File > Recover Unsaved Work로 드래프트 목록을 확인하고 복구한다. 복구는 기존
미저장 변경 확인을 거친 뒤 현재 그림을 대체한다. 복구된 그림은 파일 증식 없이
기존 드래프트 식별자를 이어받으며, 저장되지 않은 상태로 유지되어 Save를 눌러도
사본을 다운로드할 뿐 변경 표시나 드래프트를 지우지 않는다. 폐기 확인 후 다른
문서를 열거나 교체하거나 깨끗한 기준선으로 실행 취소하면 드래프트가 삭제된다. 탭을
닫거나 서버를 중단해도 드래프트는 디스크에 유지된다. 다른 창에서 열려 있는 드래프트를
복구하려면 명시적 확인이 필요하며 이전 창의 세션은 종료된다. 해당 창이
제한 대기 시간을 초과해 응답하지 못하거나 최신 승인 변경이 드래프트에
기록되지 못한 경우 인수가 거부되며, 상대 창은 열린 채 유지되므로 해당 창으로
전환해 사본을 저장하거나 쓰기 실패를 해결해야 한다. 서버가 실행 중인 상태에서
비정상 종료된 탭은 명시적으로 드래프트를 인수하거나 서버를 재시작하기 전까지
계속 열린 창으로 표시될 수 있다. 최대 16개(각각 96 MiB
문서 한도 + 64 KiB 봉투)까지 유지되며 기간 만료로 삭제되지 않는다. 쓰기 실패 시
디스크의 이전 정상 사본을 유지하고 오류를 표시하므로 최신 메모리 편집은 아직
복구되지 않을 수 있다. 손상되거나 호환되지 않는 드래프트 파일은 명시적 폐기를 위해
디스크에 보관된다. 파일시스템 오류로 드래프트 폴더를 읽거나 쓸 수 없으면 해당 실패를
보고한다.

화학 구조 복사·잘라내기·붙여넣기(Edit 메뉴 및 ⌘/Ctrl+C, ⌘/Ctrl+X, ⌘/Ctrl+V)는
별도의 화학 스키마 없이 데스크톱의 표준 v3 선택 페이로드 형식을 사용한다. 지원되는 선택
항목에 대해 원자, 결합, 완전한 고리, 귀속 및 선택된 전자 주석, 화살표, 도형, 오비탈,
텍스트 노트, 그룹(재매핑된 소속 유지), 포함된 이미지(이미지 용량 한도 내), 원근 3D
좌표(대상 카메라를 통해 원근 깊이 점만 재투영)를 보존하며, 기존 검증기는 지원되지
않거나 손상되었거나 용량을 초과한 페이로드를 원자적으로 거부할 수 있다. 원자 ID는
기존 ID 다음으로 재매핑되고, 반복 붙여넣기는 결합 길이만큼 연속 배치된다. 잘라내기는
유효한 복사본이 확보되고 원본 그림이 최신일 때만 선택 항목을 삭제한다. 붙여넣기는
1회의 실행 취소/다시 실행 편집으로 기록된다. 브라우저 API 기능은 다양하며, 이 어댑터는
브라우저 권한과 사용자 제스처가 허용될 때 비동기 일반 텍스트(`text/plain`) 클립보드
전송을 사용한다. 클립보드 접근이 불가능하거나 거부되면 현재 창의 로컬 메모리에만
유효한 사본을 보관하며 명시적 안내를 표시한다(새로 고침 시 소멸). 네이티브 Qt 커스텀
MIME은 `application/x-chemvas-selection+json`이며, 어댑터 간 직접 구현된 OS
클립보드 교환은 없다. 열린 노트 편집기는 네이티브 텍스트 편집 단축키를 유지하며,
Edit 메뉴를 열면 노트 편집을 마치고 캔버스에 클립보드 명령을 적용한다. 클립보드 접근
권한 및 동작은 브라우저마다 다르다.

용지는 사용자 지정 크기까지 Qt의 치수 계산과 중심 좌표계를 그대로 쓴다.
용지 밖에서는 그리기 시작·완료와 원자 입력을 거부하고, 결합 드래그 중 밖으로
나갔다 돌아와도 취소한다. 용지 밖 구조의 포인터 단축키 편집은 Qt와 같은 안내를
표시한다. Select 이동·삭제와 지우개는 밖의 객체를 정리할 수 있도록 허용한다.

## SMILES 삽입

SMILES 입력란과 Insert 버튼은 데스크톱의 선택적 RDKit 백엔드를 사용한다.
이 기능이 필요할 때만 기존 `rdkit` extra를 설치한다
(`python -m pip install -e ".[rdkit]"`). RDKit이 없으면 기존 데스크톱과 같은
백엔드 오류를 표시하며, 일반 드로잉에는 RDKit이 필요하지 않다.

문자열 입력 후 Insert 또는 Enter를 누르면 반투명 구조가 포인터를 따라다닌다.
시트 안을 클릭하면 한 번 삽입하며 기존 배치 계획·커밋 경로를 그대로 사용한다.
Escape, 도구 전환, 포커스 이탈, 문서 교체 또는 다른 편집은 미리보기를 취소한다.
시트 밖에서는 잔상을 숨기고 다시 들어오면 표시한다. 원자 라벨·결합 스타일·
전자 주석을 보존하고 삽입 하나가 Undo/Redo 한 단계가 된다. 저장 형식과 지원하지
않는 입체화학·동위원소 입력의 거부 규칙은 바꾸지 않았다.
세션은 현재 입력과 결합 길이에 대한 파싱 모델 하나만 보관한다. 미리보기와 글꼴
측정은 문서나 히스토리를 변경하지 않으며, 취소 뒤 늦은 응답도 잔상을 복구하지 않는다.
글꼴 엔진에 따른 렌더링 차이는 남아 있다.

File > Export MOL은 데스크톱 메뉴처럼 선택한 분자 구조를 문서 이름의
`.mol` 파일로 내려받는다. 전체 화학 구조는 Select All로 선택한다. 원자에
붙은 전자 주석에서 전하와 라디칼을 가져온다. 비어 있거나 화학 구조가 없는
선택은 거부하며, 공통 MOL 작성기가 지원하지 않는 구조와 V2000 제한을
알려 준다. 선택적 RDKit이 있으면 약어 라벨을 확장한다. 내보내기는 문서와
Undo/Redo 이력을 바꾸지 않는다.

File > Export Figure는 시트 전체를 문서 이름의 일반 SVG 파일로 내려받으며,
이름 끝의 `.chemvas`는 `.svg`로 바꾼다.
브라우저가 이 그림을 직접 그리지 않는다. 서버는 내보낼 때마다 별도 Python
프로세스를 시작하고, 이 프로세스가 현재 문서의 비공개 사본을 데스크톱의
오프스크린 캔버스에서 열어 데스크톱의 기존 SVG 그림 내보내기를 실행한다. 이
프로세스는 Qt를 사용하고, 서버가 그 내보내기를 위해 만든 비공개 임시 폴더
안에만 쓰며, 내보내기가 끝나면 종료한다. 서버는 프로세스가 끝난 뒤 그 폴더를
지우며, 내보내기가 실패하거나 중단된 경우에도 지운다. 브라우저는 결과를 일반 다운로드로 저장하며, 서버가 다른 위치에
쓰도록 하는 옵션은 없다. 열린 노트를 먼저 확정하며, 이 확정은 문서와 이력을
바꿀 수 있고 노트가 저장되지 않으면 내보내기를 멈춘다. 내보내기는 한 번에
하나만 실행하고, 내보내는 동안 바뀌거나 이름이 바뀌거나 교체되거나 작업 중·
로딩 중이 된 문서의 결과는 버린다. "There is nothing to export." 같은
데스크톱 내보내기의 메시지는 그대로 표시한다. 120초를 넘는 내보내기는 중단하고,
데스크톱 명령줄 렌더링의 크기 제한을 넘는 출력은 거부하며, Qt가 시작되지 않는
경우를 포함해 내보내기 프로세스가 실패하면 그림을 내보낼 수 없다고 알린다.
이 경우 모두 아무것도 내려받지 않는다. 내보내기 자체는 문서, 리비전과
Undo/Redo 이력을 바꾸지 않는다. 선택 영역만 내보내기, PDF·PNG·TIFF, 편집 가능한 SVG와
데스크톱 내보내기 대화상자의 옵션은 브라우저에서 제공하지 않는다.

View > Valence Checking은 데스크톱과 같은 규칙으로 전하에 비해 일반 결합이
너무 많은 원자에 밑줄을 긋는다. 수소·붕소·탄소·질소·산소·플루오린의 일반적인
전하 상태를 원자에 저장된 전하·라디칼 주석으로 검사하며, 이 주석은 표시를
더하거나 지울 때 함께 갱신된다. 약어 라벨·라디칼·점선 결합·
금속 배위는 검사하지 않는다. 밑줄은 끌어 옮기는 원자를 따라가고, 새 경고는 편집이
반영된 뒤 나타난다. 열린 그림마다 켜진 상태로 시작하는 보기 설정이며 저장이나
내보내기를 막지 않고, 밑줄은 그림이나 저장·내보내기 파일에 들어가지 않는다.
데스크톱처럼 보이는 영역에 걸친 경고만 보이는 너비만큼 그린다. 한 화면의
지그재그 점은 최대 50,000개이며, 이를 넘으면 뒤쪽 원자의 경고는 보이는
경고가 줄 때까지 생략된다.

## 남은 연결 작업

다른 개체의 핸들, 패널과 나머지 출판 출력은 기존 기능의 연결이 남아 있다.
원래 도구·메뉴 자리는 유지하고 미연결 동작은 비활성으로 표시한다.
이 기능을 대신하는 별도 간이 편집기와 그림 렌더러는 두지 않는다.

텍스트 노트와 노트 상자는 데스크톱처럼 표시되고 선택·이동·삭제·회전·
뒤집기·정렬할 수 있다. Text 도구(T)로 클릭한 곳에 노트를 추가하거나, 클릭한
노트를 전체 선택 상태로 편집한다. Esc나 바깥 클릭으로 끝내며 비운 노트는 삭제된다.
Text 페이지는 선택한 글자, 또는 편집 중이 아니면 선택한 노트 전체에 글자 크기
단계와 굵게·기울임·위첨자·아래첨자·정렬을 적용하고, Color 도구는 노트 전체의 색을
바꾼다. 선택 없이 커서만 있을 때는 데스크톱처럼 다음에 입력할 글자의 서식을 정하며,
커서를 옮기거나 붙여넣기·삭제를 하면 해제되고 서식만 바꾼 것은 저장하지 않는다.
붙여넣은 글자는 브라우저의 서식을 유지하고, 빈 줄은 문서 기본 서식을 쓴다.
입력기와 커서 위치 동작은 아직 브라우저·플랫폼별 확인이 필요하다. 열린 노트에서
실행 취소는 Ctrl+Z 또는 Cmd+Z, 다시 실행은 Ctrl+Shift+Z, Cmd+Shift+Z 또는
Ctrl+Y를 쓴다. 연속 입력이나 삭제, 새 문단, 서식 변경, 입력기로 확정한 텍스트를
각각 한 단계로 처리한다. 브라우저의 우클릭 메뉴는 자체 편집 기록에 따라
활성화되므로 실행 취소·다시 실행 메뉴가 비활성 상태일 수 있다. 맞춤법 교정은
브라우저의 서식을 유지한다. 목록이나
pt가 아닌 글자 크기를 쓴 노트는 평문으로 읽기 전용으로 연다.

바깥쪽 이중결합과 either 이중결합을 포함해 모든 결합 스타일을 표시한다.
이중결합을 우클릭하면 데스크톱과 같은 Inward·Centered·Outward 위치를 고를 수 있다.

계산 계획이 있는 문서도 편집할 수 있다. 계획의 성분 참조가 어긋나는 편집은 데스크톱
저장과 같은 경고와 함께 그 버전에서 계획을 빼며, 실행 취소로 되돌릴 수 있다.

이미지·그룹·원근 보기가 있는 문서도 편집할 수 있다. 이미지는 선택·이동·삭제·회전·
뒤집기를 할 수 있고(데스크톱처럼 픽셀은 똑바로 두고 상자만 움직인다), 도형과 함께
맨 앞으로·맨 뒤로 보내기, 정렬·분배, 그룹 만들기에 쓸 수 있다. Insert Image와
Image Properties는 데스크톱의 검증·용량 한도·배치·항목을 쓴다. 포함된 이미지
원본이 있으면 문서는 96 MiB 문서 용량 한도까지 받을 수 있고, 이미지 원본을
뺀 그림은 2 MiB 이내여야 한다. 그룹은 데스크톱의 그룹 상태를 유지한다. Edit >
Group·Ungroup(Ctrl+G, Ctrl+Shift+G), 그룹 전체로 채워지는 선택, 점선 그룹 상자,
두 그룹의 분자를 잇는 연결의 거부를 데스크톱과 같이 처리한다. 원근 보기는 저장된
깊이 점을 데스크톱 규칙으로 읽고, 반영된 편집마다 남아 있는 원자에 투영되는 점만
유지한다. Perspective Rotation 도구는 아직 연결하지 않았다. 저장 사본에는 문서 데이터를 모두 유지한다. 글꼴 렌더링, 라벨 선택 영역, 결합 접합, 서식 텍스트와
메뉴·파일 대화상자·클립보드는 브라우저·플랫폼별 연결이 필요하다.
전체 편집 기능은 Qt에서 제공한다.

서버는 loopback에만 바인딩하고 Host·Origin·실행 인증 정보를 검사한다.
정해진 정적 파일만 제공하며 메모리 세션은 최대 16개다. 한도에 닿으면
30분 이상 쓰지 않은 창의 세션을 닫아 자리를 만든다.
이미지를 뺀 그림 2 MiB, 이미지 포함 전체 문서 96 MiB, 열기·세션 HTTP 요청
98 MiB 제한을 적용한다. 원자 2,000개·결합 3,000개, 기존 히스토리 100개 명령
제한을 쓴다. 전체 프로세스 메모리 제한은 아니다. 복구 지속성은 서버의 편집 승인과 성공적인 드래프트 쓰기를 모두 필요로 하며, 쓰기 실패 시 디스크의 이전 정상 사본이 유지되므로 최신 메모리 편집은 복구되지 않을 수 있다. 입력 중인 노트 텍스트나 종료 시점에 아직 승인되지 않은 편집은 유실될 수 있으며 페이지 이탈 경고는 유지된다.

## 유지보수와 검증

`bootstrap/web_adapter.py`는 HTTP·세션·기존 서비스 연결을 담당한다.
브라우저 모듈은 통신·SVG 표시·DOM 이벤트를 맡고, 편집 알고리즘은 기존 소유자에 둔다.
Qt에 묶인 경계는 점 생성 함수를 받거나 외부 트랜잭션의 후보 편집을 허용하되,
기존 Qt 기본 동작은 유지한다. 별도 편집 엔진, 별도 그림 렌더러, 도구별 전달 파일,
복사한 롤백 블록을 추가하지 않는다. [ADR 0029](adr/0029-browser-adapter.md)를 따른다.

`make check`는 Qt 없는 import, 실제 HTTP, 제거한 시험판 동작 거부,
편집 실패 시 상태 보존, Undo/Redo, 문서 보존과 JavaScript를 검사한다.
테스트에는 Node.js 20+가 필요하다. `tests/test_web_clipboard.py`,
`tests/test_web_drafts.py`, `tests/web_adapter.test.mjs`로 클립보드 페이로드,
붙여넣기 계획, 드래프트 잠금, 봉투 저장, 인수 및 세션 클라이언트 복구 동작을
검증한다. 실제 Qt와 웹에 같은 결합 생성·클릭 방향·벤젠 붙이기·융합·삭제·결합 스타일·
원자 표기·겹친 원자 병합·원자/결합 이동을 실행해 결과를 비교한다.
두 가지 결합 길이와 고리 기록 유무별 선 좌표, 웹 → Qt 저장 → 웹 편집·Undo →
Qt 재열기도 검사한다. 제스처와 배치는 실제 브라우저로 확인한다.
클립보드 동작은 브라우저와 플랫폼에 따라 차이가 있으며, 전체 화면·복구·출력의
동등성은 아직 검증되지 않았고 Qt 종료는 별도 인수 검증 뒤 결정한다.

브라우저의 화살표 드래그 기준은 화면상 맨해튼 거리 10px이다. 브라우저는 데스크톱 시스템 드래그 거리 설정을 읽을 수 없으며 Qt는 기존 시스템 설정을 유지한다. 선택한 화살표·선을 옮길 때 움직인 끝점이 현재 배율에서 화면상 12px 안에 다른 화살표·선의 끝점에 닿으면, 데스크톱의 선택 드래그처럼 그 끝점에 붙고 선택 전체가 그만큼 이동한다. 이동 미리보기와 놓을 때 같은 규칙을 쓴다. 데스크톱이 이 드래그 중에 보여 주는 연결 표시는 아직 브라우저에 없다.

선택은 문서 버전에 묶인 세션 조회로 그래픽 히트와 장면 좌표를 판정하며, 문서 변경이나 재렌더링을 하지 않는다. 일반 선택은 기존 구조 우선순위 정책을 사용하고, Shift 선택·지우개는 실제 원자/결합 히트와 기존 근접 결합 판정을 사용한다. 고정된 웹 결합 클릭 폭은 제거했다. 응답 전 마우스를 놓아도 최종 좌표를 보존하며 취소·문서 변경 뒤의 늦은 응답은 버린다. 지우개 판정과 삭제는 하나의 후보 편집으로 처리한다. Qt의 화살표 주변 6 화면 픽셀 보조 판정과 투명한 고리 내부 선택도 연결했다.


Ring Fill은 기존 완전한 고리 판별과 불투명 파스텔 혼합을 사용한다.
고리 내부, 고리의 모든 원자 또는 모든 결합을 선택한 뒤 채우기 색상을 고른다.
일부 원자와 일부 결합을 합쳐 새 고리를 만들지 않는다. Ring Fill 팔레트를 열어도
Select 도구는 유지된다. 투명한 고리 내부도 Shift 선택·이동·Color·지우기의 대상이다.
Color는 고리의 원자와 결합을 칠하고, 고리 내부 지우기는 채우기만 제거한다.
Undo로 이전 상태를 복구한다. 같은 거리의 결합도 기존 공간 검색 순서로 선택한다.


빈 캔버스를 드래그하면 방향에 관계없이 영역에 닿은 도형을 선택한다.
macOS의 Command, 다른 플랫폼의 Control을 누르면 기존 선택에 추가한다.
Qt에서 가져온 실제 SVG 도형의 교차 판정을 사용하므로 투명한 고리와 타원 내부도
선택되며, 외접 사각형만 겹친 경우는 선택하지 않는다. 선택 자체는 히스토리에 기록하지
않고 이후 이동·삭제는 기존 경로를 쓴다. Escape·포커스 이탈·도구/문서 변경은 진행 중인
선택을 취소하며 늦은 서버 응답을 무시한다. 드래그 사각형은 브라우저의 시스템 Highlight
색상을 쓰므로 Qt의 플랫폼별 드래그 사각형 외관과 차이가 있을 수 있다.
현재 영역 선택은 SVG 교차 API가 있는 브라우저에서 지원한다. Firefox처럼 이 API가
없는 브라우저에서는 드래그를 취소하고 이전 선택을 복원한 뒤 안내를 표시한다.
이 경우 Shift 클릭·전체 선택을 사용하거나 Qt 버전에서 영역을 선택할 수 있다.

선택한 화살표·선은 원래 경로와 Qt 선택 폭을 사용하며, 그림 위에 화면 기준
1.5px 외곽선을 표시한다. 머리와 몸통의 부분 경로가 겹치는 경계도 유지한다.
SVG 마스크가 선의 경계를 표현하므로 Qt나 별도 화살표 기하 알고리즘을 쓰지 않는다.
곡선·접합부에서는 SVG와 Qt 경로 스트로커 및 안티앨리어싱 차이가 남을 수 있으며,
픽셀 단위로 같은 렌더링을 보장하지 않는다.

분자 선택은 기존 결합 띠·원자 표시 범위·연결 컴포넌트 계산을 사용한다. 문서 버전에
묶인 읽기 전용 조회로 현재 선택의 도형을 받고, 이동 미리보기는 같은 후보 문서에서
선택 도형도 반환한다. 선택 변경 뒤 도착한 이전 응답은 버린다. 고리 내부 선택은
외곽선을 위해 고리의 원자로 확장하고, 연결된 무표시 탄소에는 개별 색칠 원을 그리지
않는다. SVG morphology가 컴포넌트의 합쳐진 알파 영역 경계를 표시하므로 브라우저에
그래프·결합 알고리즘을 복제하지 않는다. 래스터 커널은 모서리·작은 배율에서 Qt의
벡터 합집합과 차이가 있다. 라벨 선택에는 기존 레이아웃 사각형·문서 여백·원형 또는
확장 여백 계산을 공유한다. 잉크 영역은 글자 클릭 판정에만 사용한다. 기존의 원 지름
3배 기준으로 원형과 확장 상자를 결정하고, 측정 완료와 미리보기에도 해당 후보의
레이아웃 범위를 함께 전달한다. 글꼴 엔진 측정 차이는 남아 있다.
일반 원자·화살표 라벨의 행 높이는 브라우저의 기본 글꼴 행을 2048픽셀 em에서
측정한 뒤 크기를 다시 맞추고 기존 문서의 올림 계산을 적용한다. 작은 HTML span의
반 픽셀 반올림 없이 글꼴의 행 간격을 유지한다. Arial, Times New Roman,
Courier New의 8–64픽셀, 일반·굵게·기울임에 대한 기존 브라우저 측정 비교 513건에서
macOS 문서 높이와 일치한 것으로 기록되어 있다. 모든 설치 글꼴이나 대체 글꼴의
동일성을 보장하지 않으며, 휠의 줄 단위 delta는 일반 CSS 행 높이를 계속 쓴다.

Select의 각도 입력란과 Rotate 버튼은 원래의 수치 회전 명령을 쓴다. Edit → Rotate는
그 입력란으로 포커스를 옮긴다. 기본값은 15도, 범위는 -180–180도이며 1도 단위 증감
버튼이 있고 Enter로 입력한 각도를 적용한다. 선택한 결합과 고리 채움은 원자 ID로
확장한다. 회전 중심은 원자 위치, 화살표 끝점·제어점 범위와 데스크톱의 도형 범위를
쓰고 라벨 범위는 넣지 않는다. 원자 좌표, 주석 기록과 고리 다각형은 원래의 변환·이동
서비스를 쓴다. 도형은 Qt처럼 중심만 회전 중심을 따라 돌고 자신은 똑바로 유지한다.
한 번 적용하면 Undo/Redo 항목 하나가 생기며, 빈 선택이나 0도는 항목을 만들지 않는다.
미리보기와 거부된 편집은 문서를 바꾸지 않는다. 좌우·상하 뒤집기도 같은 선택 전체
회전 중심과 원래의 주석 변환을 쓴다. 데스크톱의 Select 아이콘, Edit 메뉴 동작과
Command/Control+Shift+H/V 단축키를 연결했다. 평형 화살표 반전과 위·아래 라벨 교환,
원호 방향, 도형 범위는 원래 변환을 따른다. 길이가 0인 평형 화살표가 있으면 어떤
변경도 하기 전에 편집 전체를 거부한다. 반복해서 뒤집으면 데스크톱 직렬화기가
생략하던 false 반전 표시를 지우면서 기록의 동일성은 유지한다. 뒤집기마다 Undo/Redo
항목이 하나 생기며, 빈 선택과 바뀌지 않는 선택은 항목을 만들지 않는다.

정렬과 같은 간격 분배는 원래 데스크톱의 객체 묶음과 사각형 차이 계산을 쓴다. 원자,
결합, 고리 중 하나를 선택하면 연결된 분자 전체가 내부 형태를 바꾸지 않고 움직인다.
정렬 아이콘 6개, 분배 아이콘 2개와 Edit 하위 메뉴는 원래 정의를 쓴다. 분배할 때 양
끝 객체는 고정되며, 객체가 2개(분배는 3개)보다 적으면 아무것도 하지 않는다. 범위에는
원자 라벨 배치 전체와 데스크톱 경로 항목의 선 범위가 들어가며, Qt처럼 화살표
라벨은 부모 항목의 정렬 상자를 키우지 않는다. 글꼴 측정값이 없으면 편집을 거부한다.
후보 미리보기, 반영, Undo/Redo는 기존 문서·이력 경로를 쓴다. 그룹은 하나의
객체로 정렬·분배한다.

대각선의 둥근 선 끝은 이제 범위에 Qt의 3차 제어점 외곽을 넣어, 칠한 원의 상자를
쓰던 때의 작은 정렬 오차를 고쳤다. 곡선 화살표 범위는 아래에 적은 근사를 유지하므로
그 정렬에 문서화된 좌표 오차가 남을 수 있다.

선택 프레임과 회전 손잡이는 데스크톱의 표시 조건, 여백, 모서리 반경, 줄기와 손잡이
크기를 쓴다. 프레임은 원자 라벨 배치 전체와 화살표 라벨 블록을 포함한다. Qt처럼
원자 두 개를 선택하거나 화살표·선 하나를 선택하면 프레임이 생기고, 도형만 선택하면
생기지 않는다. 수치 회전의 회전 중심에 선택한 도형이 들어가도 도형 범위는 보이는
프레임에서 뺀다. 프레임은 외곽선 위, 객체 손잡이 아래에 놓이고 회전 손잡이는 화면에서
같은 크기로 유지된다.

회전 손잡이를 끌면 포인터 위치를 원래의 회전 각도 함수에 보내고, Shift를 누르면
데스크톱처럼 15도 단위로 맞춘다. 미리보기마다 직전 미리보기가 아니라 누를 때 확정된
상태를 변환한다. 놓으면 이력 명령 하나를 적용하고, Escape나 취소는 미리보기를 버리며
누른 위치로 돌아오면 정확히 아무것도 바꾸지 않는다. 늦게 온 미리보기는 끝났거나 취소한
드래그를 덮어쓰지 못한다.

Qt의 경로 항목 범위는 선을 그은 3차 제어점 외곽을 쓴다. 브라우저는 2차 명령을
제한된 횟수로 나눈 오프셋 제어점 범위로 바꾸며, 그리는 화살표 경로는 바꾸지 않는다.
선 끝·접합 외곽과 양쪽을 따로 나누는 계산은 근사이며, 데스크톱과 비교한 684개
경우의 최대 좌표·크기 오차는 둥근 끝 보정 뒤 6단위 펜에서 문서 단위 1.93이다.
처음의 나누지 않은 제어점 범위가 심하게 굽은 곡선에서 커지던 문제(약 195단위)는
고쳤다. 모든 곡선에서 Qt 프레임 형태와 정확히 같다거나 픽셀이 같다는 뜻은 아니다.

도형 선택은 기존 타원·사각형 경로와 Qt 선택 여백을 사용한다. 테두리 없는 도형과
납작한 도형도 포함한다. 분자와 같은 SVG 경계 렌더러로 개별 외곽선을 내용 위,
크기 조절 핸들 아래에 표시하며 이동·크기 조절 미리보기는 후보 문서의 경로를 쓴다.
Qt 도형 선택에도 winding 채움 규칙을 명시해 테두리 없는 사각형 안쪽에 생기던
구멍을 고쳤다. SVG에서 두 단계의 선 폭을 합쳐 그리는 방식은 납작한 끝부분에서
약간 다르다. Qt 영역 표본은 경계에서 0.25문서 단위 밖에서 일치하며, SVG 모서리와
안티앨리어싱 차이도 남아 있다. 픽셀 단위의 동일성은 아직 보장하지 않는다.

상태 표시줄의 격자 컨트롤은 None → Hex → Square → None 순서로 바뀌며 데스크톱의
15%, 20%, 25% 농도를 제공한다. View → Snap to Grid는 현재 형식을 켜고 끈다.
데스크톱의 배경 선분을 장면 원점 기준의 제한된 SVG 타일로 만들며, 간격은 현재 결합
길이의 절반이다. 화면에서 6픽셀보다 좁으면 격자는 숨기지만 스냅은 유지한다.
화살표·선 그리기와 끝점 핸들은 원래의 끝점 → 명시적 각도 → 격자 순서를 쓰고, 분자,
도형, 곡선 중앙점은 기존 동작을 유지한다. 격자 선택은 잠시 쓰는 도구 상태이며 문서
설정이나 Undo 항목으로 저장하지 않는다. SVG와 Qt의 안티앨리어싱은 다를 수 있다.
