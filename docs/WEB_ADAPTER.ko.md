# 브라우저 어댑터

[English](WEB_ADAPTER.md)

기존 Chemvas 편집기의 화면·입력을 브라우저 어댑터로 옮기는 작업이다.
Qt 앱을 함께 유지하며, 전체 사용 흐름과 화면의 동등성을 목표로 개발 중이다.

## 실행

```bash
python -m pip install -e .
chemvas --ui web
chemvas --ui qt
```

`make check` 이후 macOS/Linux는 `.venv/bin/chemvas`, Windows는
`.venv/Scripts/chemvas.exe`를 사용한다. Python 3.12+가 필요하다.
`chemvas --ui web --no-browser`는 실행 URL을 출력한다. 터미널을 유지하고
Ctrl+C로 서버를 종료한다. URL의 세션 인증 정보는 로컬에서만 사용한다.
프런트엔드 빌드·CDN·Node 런타임은 필요하지 않다. 웹 경로는 Qt를 import하지
않으며, 통합 패키지는 데스크톱 앱을 위해 Qt를 계속 설치한다.

## 연결된 기존 구현

- 도구 순서·이름·툴팁·결합 옵션·상태 안내는 기존 `main_window_config`에서 읽는다.
  SVG 아이콘, 색상, 버튼 크기와 ACS1996 그리기 기본값도 양쪽이 공유한다.
  옵션바는 Qt의 흰색 선택 박스·옅은 테두리·그룹 간격을 사용한다.
- 결합 생성은 `StructureBondBuildService`와 `StructureBuildCommitter`가 실행한다.
  결합 입력은 장면 좌표를 보내고 기존 원자 우선 판정과 공통 반경을 쓴다.
  결합 위에 놓으면 기존 끝 원자 스냅 규칙을 적용하며 각도 간격은
  `CanvasToolSettingsState`에서 읽는다. 기존 원자·결합 재사용은 원래 생성기가
  담당한다. 웹은 손을 놓을 때 확정하고 Qt는 결합을 누르는 즉시 스타일을 바꾼다.
- 벤젠 삽입은 `StructureBenzeneBuildService`와 같은 커미터를 호출한다.
  클릭 대상은 Qt의 원자·결합 거리 우선순위와 삽입 허용 반경으로 판정하고,
  원자 선택 원도 기존 반경을 쓴다. 붙이기, 융합, 원자 합치기, 결합 차수와
  고리 기록을 그대로 사용한다. 글자 영역의 선택 모양은 아직 웹 글자 배치에
  의존하므로 Qt와 완전히 같지는 않다.
  삭제는 항목 수에 관계없이 같은 선택 삭제 요청으로 기존 삭제 계획을 실행한다.
- 굵은 결합(Bold)은 기존 `BondGraphicsDrawService`의 다각형을 표시한다.
  이중·삼중 결합의 차수, 고리 방향과 인접 굵은 결합 접합 계산을 그대로 쓴다.
- 점선 결합(Dotted)의 점 위치·반지름·접합부 간격은 기존
  `BondLineGeometryService.dotted_bond_dots`를 사용한다. 이중 결합에 적용할 때도
  원래 차수와 안쪽/바깥쪽 규칙을 유지한다. SVG는 전달받은 원만 표시한다.
- 원자 라벨의 방향·별칭 기준점·아래첨자·수소 세로 배치는 기존 함수를 쓴다.
  브라우저는 글자 폭과 줄 높이를 측정해 Python 배치 함수에 전달하고,
  계산된 글자 위치를 포인트 단위로 표시한다. 원래 원자 기호는 바꾸지 않는다.
  글꼴 렌더링과 글자 경계에 맞춘 결합 자르기는 아직 검증·연결이 남아 있다.
- SVG 결합 선은 기존 `BondGeometryPlanService`, `BondLineGeometryService`,
  `BondRingDoubleGeometryService`의 결과를 표시한다. 고리 중심 선택도 공유한다.
  양쪽 모두 현재 문서의 고리 순서를 캐시된 그래프 고리보다 우선한다.
- 원자 도구는 기존 `AtomLabelService`와 `AtomLabelMergeService`를 호출한다.
  탄소 표시, 겹친 원자와 중복 결합의 병합, 비탄소 기호 숨김 거부 규칙을 공유한다.
  입력창 속성과 클릭 대상·입력 계획도 Qt 소유자에서 가져온다.
- 선택 항목 이동은 기존 `CanvasMoveController`를 호출한다. 결합 끝점은 기존
  선택 확장 함수로 중복 없이 계산하고, 고리 채움은 기존 polygon 갱신기로 맞춘다.
  드래그 미리보기와 확정 편집은 같은 서버 경로를 쓴다.
- Undo/Redo는 기존 `CanvasHistoryService`와 `CanvasHistoryState`가 담당한다.
  서버가 기존 연산으로 임시 후보를 만들고 검증·기록한 뒤 승인된 상태를 전달한다.
  기록에는 문서만 저장하고 Undo/Redo 때 기존 렌더러로 화면을 다시 계산한다.
  재계산 실패 시 기존 이력 트랜잭션이 문서와 기록을 유지한다.
  JavaScript는 승인된 상태를 표시한다. 응답이 끊기면 편집을 재전송하지 않고
  서버의 현재 문서를 읽는다. 읽기도 실패하면 다음 동작은 재연결만 수행하고,
  갱신된 문서를 확인한 뒤 다시 편집하도록 안내한다.

A로 원자 도구를 선택한다. 상단에 기호를 입력한 뒤 클릭하면 해당 기호를 적용하고,
입력창이 비어 있으면 기존 원자 기호를 담은 대화상자를 연다. 취소는 문서를 바꾸지 않는다.
X로 결합을 그리고 J로 벤젠을 놓거나 기존 원자·결합에 붙인다.
결합 도구에서 B를 누르면 Bold를 선택한다.
Space로 선택하고 드래그해 이동한다. Shift+클릭으로 선택을 추가·해제하고,
⌘/Ctrl+A로 전체 구조를 선택한다. Delete는 선택 전체를 한 명령으로 삭제하며
지우개는 클릭한 항목을 삭제한다. Escape·도구 전환·포커스 이탈은 미리보기를 취소한다. 결합을 클릭하면 선택한 스타일을
적용하고, 결합 도구의 짧은 클릭은 기존 기본 방향으로 결합을 만든다.
제스처 하나를 Undo 한 번으로 취소한다.
일반 휠은 스크롤하고 Ctrl+휠은 포인터 중심으로 확대한다. 배율 제한(20–500%)과
버튼 간격은 데스크톱 선언을 공유한다. 브라우저 픽셀 입력은 Qt의 각도/픽셀 비율로
변환하고 줄·페이지 입력은 글줄 높이·화면 크기를 사용한다. 브라우저는 Qt 각도 입력을
제공하지 않으므로 실제 장치의 휠 감도는 다를 수 있다.
F5–F8로 확대를 조절한다.

File → Open으로 `.chemvas`를 열고 Save로 사본을 다운로드한다.
버전 7–9의 문서 버전과 데이터를 유지하며 Qt에서도 사본을 열 수 있다.
다운로드 시작만으로 디스크 저장 완료를 확인할 수 없어 변경 표시와 종료 경고는
유지한다. 브라우저 자동 저장·복구는 아직 연결하지 않았다.

## 남은 연결 작업

텍스트·화살표 편집, 사각 영역 선택과 선택 외곽선·핸들, 패널, SMILES,
화학 클립보드와 출판 출력은 기존 기능의 연결이 남아 있다.
원래 도구·메뉴 자리는 유지하고 미연결 동작은 비활성으로 표시한다.
이 기능을 대신하는 별도 간이 편집기와 SVG 내보내기는 두지 않는다.

텍스트·화살표·이미지·그룹·추가 주석·미지원 스타일이 있는 문서는
불완전한 읽기 전용 미리보기로 연다. 저장 사본에는 원본 데이터를 유지하고
편집 요청은 거부한다. 글꼴 측정, 라벨 자르기, 결합 접합, 서식 텍스트와
메뉴·파일 대화상자·클립보드는 브라우저·플랫폼별 연결이 필요하다.
전체 편집 기능은 Qt에서 제공한다.

서버는 loopback에만 바인딩하고 Host·Origin·실행 인증 정보를 검사한다.
정해진 정적 파일만 제공하며 메모리 세션은 최대 16개다.
요청 2 MiB, 원자 2,000개·결합 3,000개, 기존 히스토리 100개 명령 제한을 쓴다.
전체 프로세스 메모리 제한은 아니다. 새로 고치거나 닫으면 미저장 작업을 잃을 수 있다.

## 유지보수와 검증

`bootstrap/web_adapter.py`는 HTTP·세션·기존 서비스 연결을 담당한다.
브라우저 모듈은 통신·SVG 표시·DOM 이벤트를 맡고, 편집 알고리즘은 기존 소유자에 둔다.
Qt에 묶인 경계는 점 생성 함수를 받거나 외부 트랜잭션의 후보 편집을 허용하되,
기존 Qt 기본 동작은 유지한다. 별도 편집 엔진, 도구별 전달 파일,
복사한 롤백 블록을 추가하지 않는다. [ADR 0029](adr/0029-browser-adapter.md)를 따른다.

`make check`는 Qt 없는 import, 실제 HTTP, 제거한 시험판 동작 거부,
편집 실패 시 상태 보존, Undo/Redo, 문서 보존과 JavaScript를 검사한다.
테스트에는 Node.js 20+가 필요하다. 실제 Qt와 웹에 같은 결합 생성·클릭 방향·
벤젠 붙이기·융합·삭제·결합 스타일·원자 표기·겹친 원자 병합·원자/결합 이동을 실행해 결과를 비교한다.
두 가지 결합 길이와 고리 기록 유무별 선 좌표, 웹 → Qt 저장 → 웹 편집·Undo →
Qt 재열기도 검사한다. 제스처와 배치는 실제 브라우저로 확인한다.
전체 화면·복구·출력의 동등성은 아직 검증되지 않았으며 Qt 종료는 별도 인수 검증 뒤 결정한다.
