# 서체 호환성 검토 — 제안 설계

[English](FONT_COMPATIBILITY_REVIEW.md)

이 문서는 측정에 기반한 설계안이며 구현된 GUI나 승인된 문서 변환이 아닙니다.
renderer와 원본은 바꾸지 않습니다. 아래 Windows 미리보기 조합은 이미 설치된
서체를 사용하므로 새로운 설치를 전제로 하지 않습니다.

## 검사 단위

실제 내보내기 run별 문자 부분집합·face·스타일을 검사합니다. 하나의 서체가 문서
전체를 지원해야 한다는 조건은 두지 않습니다. 원본 316개 span은 각 Mac face로
모두 그려지며 `₆` 한 번과 `−` 여섯 번은 이미 Helvetica로 분리돼 있습니다.
다른 캡션은 Apple SD Gothic Neo, 원자·표시는 Arial을 사용합니다. 고유 169문자에는
완성형 한글 98종이 있고 결합문자는 없습니다. `Δ`, `‡`, `⁻`, 아래첨자 숫자는
한글·라틴 문자와 구별해 검사합니다.

현재 Windows에서 Apple/Helvetica 요청의 논리 이름은 Arial로 바뀝니다. 실제
native EMF에는 한글의 Gulim, 일부 첨자의 Microsoft Sans Serif fallback이
나타납니다. 글자가 그려지는 것과 원본 face·배치가 유지되는 것은 별도 판정입니다.
목록 API와 실제 face도 구분합니다. 앞선 GDI 교집합에 없었던 WPF Gill Sans 요청은
이 환경에서 Gill Sans Ultra Bold로 해석됩니다.

## 경고와 최소 선택

대상 환경을 지정한 CDXML 검토에서 한 번만 범위를 좁혀 알립니다.
“이 문서는 현재 Mac에서 그려집니다. 선택한 Windows 대상은 Apple SD Gothic Neo와
Helvetica를 대체하므로 같은 외형과 배치는 아직 검증되지 않았습니다.”
169문자 전체가 누락됐다고 표현하거나 서체 설치를 필수로 요구하지 않습니다.
편집·일반 내보내기는 유지하고 기존 엄격한 native 승인 조건은 별도로 적용합니다.
대상 정보가 없으면 ‘미검증’이며, 원본의 의도된 fallback 자체는 경고가 아닙니다.

선택지는 두 개이며 첫 항목이 기본입니다.

1. **원본 서체 유지.** 원본 run을 보존하고 대상의 치환 가능성을 표시합니다.
2. **별도 Windows 파생본 미리보기.** 실제 제목·한글·화학식·기호를 대상의 확인된
   기존 face로 미리 봅니다. 사용자가 새 사본 생성을 선택하기 전에는 적용하지 않습니다.

측정된 Windows 안은 Malgun Gothic regular/bold를 기본으로 쓰고, 해당 face가
지원하지 않는 `⁻`, `₆`, `−`에 Tahoma를 배정합니다. 두 face의 합집합은 169문자를
지원합니다. 실제 ChemDraw의 12개 대조군은 `FPh / OMe`, `Ar = 4-FC₆H₄`, 한글
캡션, `ΔGcomp`, `(kcal mol⁻¹)`, `−50`의 원본 요청과 명시적 대체를 비교합니다.
문자·스타일은 보존하지만 원본 Mac 외형이나 전체 배치 일치의 증거는 아닙니다.
Unicode 기호를 다른 문자로 치환하거나 합성 bold를 몰래 적용하지 않습니다.

## 미리보기와 검증

Mac 원본, Windows 현재 자동 대체, 명시적 Windows 안을 나란히 보여줍니다.
실제 face·버전·스타일과 fallback 경계를 표시합니다. Malgun Gothic이 없는 Mac의
자동 fallback을 진짜 Malgun 미리보기로 제시하지 않습니다. 실제 대상 렌더 근거가
없으면 ‘대상 미리보기 이용 불가’로 표시합니다. 검토 번들의 native 그림은 문서
내보내기 결과이며 스크린샷이나 완성된 GUI가 아닙니다.

파생본은 문자 순서와 스타일을 유지하고 글리프·시작점·기준선·줄바꿈·겹침·범위를
확인한 뒤 그 새 문서에 대해 기존 native 검증을 수행합니다. 문자 지원 통과가
전체 fidelity 통과가 되지 않도록 원본 판정과 파생본 판정을 구분합니다.

## 소유권과 저장 제안

현재 exporter의 shaped-run 분할과 UTF-16/cluster 거부 규칙을 재사용합니다.
원본 해시·대상 환경·face 버전·run 문자에 검증 근거를 묶고 변경되면 무효화합니다.
요청 face 부재, 해석 face의 문자 부재, 예상 밖 물리 fallback, 배치 미측정을
구분합니다. 조회는 부작용 없이 수행하며 Qt·OS adapter가 수집한 typed 관찰값을
순수 export 기능에 전달합니다. 원격 조회나 폰트 설치를 내장하지 않습니다.

승인된 안은 기존 텍스트 포맷·문서 소유자를 통해 복제본에 적용하고 명시적인 새
경로와 덮어쓰기 거부를 사용합니다. 기본값·열린 원본·전체 font alias·허용 오차는
바꾸지 않습니다. 향후 원본 내 편집 기능을 만든다면 별도 사용자 의도와 하나의
되돌릴 수 있는 history transaction이 필요합니다. 현재 설계는 schema·GUI·native
bridge·자동 서체 매핑 동작을 구현하지 않습니다.
