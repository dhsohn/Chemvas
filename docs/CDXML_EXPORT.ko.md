# CDXML 내보내기

[English](CDXML_EXPORT.md)

Chemvas는 파일 > 그림 내보내기(`.cdxml` 형식)와 CLI
`render-document --output file.cdxml`로 편집 가능한 CDXML(ChemDraw XML)을
내보냅니다.

**이 출력은 ChemDraw에서 검증되지 않았습니다.** CDXML 가져오기는 지원하지
않으며, `.chemvas` 형식이 문서 원본입니다.

## 지원

| 영역   | 출력 내용                                                |
|--------|----------------------------------------------------------|
| 원자   | 순수 원소(주기율표), 색상, 명시적 C, Charge 주석           |
| 결합   | single/1, double_center/2, triple/3                      |
| 직선   | 머리 없는 실선, 끝점 순서 BoundingBox                     |
| 화살표 | 그룹 선 구성요소(축 + 머리), M/L 경로 명령만               |
| 도형   | rect, circle; 선만, 채움만, 또는 같은 색                  |
| 노트   | 줄별 `<t>`, 실행별 실제 폰트 패밀리, 크기, 굵기, 색상      |

## 거부 (파일 작성 전 오류 발생)

| 영역   | 거부 내용                                                |
|--------|----------------------------------------------------------|
| 원자   | 별명(Ac/Ts 포함), 라디칼, 장면 마크; 숨겨진 원자는 제외되고 해당 결합은 거부됨 |
| 결합   | 쐐기, 해시, 굵은, 점선, double_either, 고리 옆; 스타일/순서 불일치 |
| 직선   | 파선, 물결, 굵은; 미러                                    |
| 화살표 | 곡선, 이중, 기타 종류, 라벨, 미러                          |
| 도형   | 타원, 둥근 사각형, 파선/점선 획, 반투명 채움, 혼합 색상     |
| 노트   | 이탤릭, 밑줄(대시/점/물결 포함 모든 스타일), 윗줄, 취소선, 아래/위 첨자, 대소문자 변환(대문자, 작은 대문자), 사용자 지정 단어 간격, 기본값 외 폰트 확장, 목록, 표, 회전, 400/700 이외 두께, 왼쪽 정렬 아닌 경우, 상자/테두리, 글리프 대체 폰트(CJK/이모지 포함) |
| 겹침   | 프래그먼트 레이어 교차, 겹치는 교차 프래그먼트. 기본 z값에서 바운딩 렉트가 결합된 분자의 항목에 닿는 노트·직선·화살표는 거부되며, 항목 경계가 닿는 두 결합 분자(픽 헤일로 포함)도 거부됨 |
| 기타   | 고리 채움, 괄호, 이미지, 오비탈, 원근법, 그룹, 빈 페이지    |

## 축척

하나의 균일 축척 `s = out_w_pt / source_w`가 모든 좌표, 폰트 크기, 선 너비,
기하에 적용됩니다. `--width-mm`을 지정하지 않으면 CLI는 결합 길이 기준으로
크기를 정합니다(고정 페이지 너비 없음). GUI 사용자 지정 너비 기본값은
84 mm입니다. 170 mm 페이지는 `--width-mm 170`으로 지정합니다.
수치 정밀도는 유효 숫자 12자리입니다.

## 폰트 처리

폰트 패밀리는 요청된 이름이 아닌 실제 해석된 폰트(`QFontInfo`)입니다.
텍스트 실행의 글리프가 다른 폰트로 대체되면(`QTextLayout.glyphRuns()`로 감지)
대체 폰트와 기본 폰트를 명시하는 오류와 함께 내보내기를 거부합니다.

## GUI 및 CLI

- **GUI**: 파일 > 그림 내보내기 > CDXML 형식. 대화상자 라벨:
  "CDXML - ChemDraw XML (not verified in ChemDraw)".
- **CLI**: `chemvas render-document doc.chemvas --output out.cdxml`
  (`--width-mm`, `--background`도 사용 가능). `--min-font-pt`는
  CDXML 출력에서 지원하지 않습니다.

## 원본 형식

`.chemvas` 원본 문서는 내보내기로 수정되지 않습니다. CDXML 가져오기는
거부되며, 왕복 변환은 없습니다.

## 제한 사항

- 그룹화된 화살표와 도형은 네이티브 ChemDraw 반응 도구가 아닌 CDXML
  그래픽으로 내보내집니다.
- 소비자 상호운용성 검증은 수행되지 않았습니다.
- DTD는 포함되지 않으며 DTD 유효성은 주장하지 않습니다.
- 폰트 charset, U+2028 소프트 줄바꿈, 탭 문자, 둥근 끝/연결, 수소 추론,
  `CaptionLineHeight`는 출력되지만 소비자 동작은 검증되지 않았습니다.
