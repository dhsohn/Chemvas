# 작업 문서 호환성

[English](DOCUMENT_COMPATIBILITY.md)

Chemvas의 작업 파일은 **CDXML (`.cdxml`)**입니다. 기존 `.chemvas` 파일은 더 이상
지원하지 않습니다. JSON 파일의 확장자만 바꾸어도 열리지 않으며, 기존 파일을
자동으로 수정하거나 삭제하지 않습니다.

새 문서는 그룹, 서식 있는 노트, 이미지, 도형, 화살표, 궤도, 설정을 포함한 편집 상태를
CDXML 내부의 무결성 검증 스냅샷에 보존합니다. 지원하는 구조와 그래픽은 네이티브
CDXML 객체로 저장하고, 네이티브 표현이 없는 그리기 스타일은 PNG 외형도 함께 저장합니다.
Chemvas에서 저장하고 다시 열면 편집 상태가 유지됩니다.

ChemDraw 등에서 네이티브 XML을 수정하면 스냅샷을 무효화하고 수정된 네이티브 객체를
읽습니다. 따라서 다른 편집기를 거쳐 돌아오면 Chemvas 전용 그룹·설정이나 이미지로
표현된 요소의 원래 편집 방식은 유지되지 않을 수 있습니다.

가져온 단일 페이지 CDXML은 편집 가능한 표시 범위 밖의 원본 정의도 보존합니다.
지원하지 않는 파괴적 편집은 대상 파일을 교체하기 전에 저장을 거부합니다.
바이너리 CDX와 여러 페이지 CDXML은 지원하지 않습니다.

MOL은 가져오기로 열고, 작업 사본을 CDXML로 저장합니다. SVG는 그림 출력용이며
내장된 Chemvas 편집 데이터는 더 이상 읽거나 쓰지 않습니다.
SVG·PDF·PNG 그림 내보내기도 유지됩니다. 내부 JSON 스냅샷은 실행 취소·클립보드·복구에만
사용하며 사용자 작업 파일 형식이 아닙니다.

[ADR 0059](adr/0059-cdxml-only-working-documents.md)를 참고하세요.
