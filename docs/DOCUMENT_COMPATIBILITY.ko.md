# 문서 호환성 정책

[English](DOCUMENT_COMPATIBILITY.md)

## 기본 약속

Chemvas는 향후 버전이 업데이트되더라도 기존에 작성된 정상적인 **v7 `.chemvas` 문서**를 계속 열고 편집할 수 있도록 하위 호환성을 보장합니다. 과거 파일을 열기 위해 구버전 앱을 따로 설치할 필요가 없습니다.

- **기준 규격**: 2026-09-13 기준 v7 규격(전하/라디칼 색상, 평형 화살표, `double_either` 결합, 이미지, 그룹, Calculation Plan v2 등)을 지원합니다.
- **안전한 열기**: 파일을 단순히 여는 것만으로는 원본 파일의 내용이 변경되지 않습니다.
- **저장 시 규격화**: 문서를 명시적으로 저장할 때 현재 버전 형식으로 정규화되지만, 기존 내용은 온전히 보존됩니다.

## 형식 변경 원칙

- **앱 버전과 파일 형식 버전 분리**: 앱 릴리스 버전과 문서 파일 형식 버전은 독립적입니다. 현재 기본 저장 형식은 **v8, schema 1**(Chemvas 0.18.0 이상에서 지원)이며, v7 파일 읽기를 영구적으로 지원합니다.
- **하위 호환성 기준**: 이전 버전의 판독기가 해석할 수 없는 직렬화 변경이 발생할 때만 새 문서 형식 버전을 부여합니다.
- **엄격한 유효성 검사**: 알 수 없는 형식 버전, 잘못된 필드 구조, 손상된 파일은 임의로 데이터를 버리거나 무시하지 않고 명확한 진단 오류를 보고합니다.

## v8 형식 규격

기능 추가에 따른 호환성과 파괴적 변경을 명확히 구분하기 위해, v8 형식부터는 루트 JSON 객체에 개정 번호(`schema`)와 최소 요구 버전(`min_reader`)을 포함합니다:

```json
{
  "type": "chemvas",
  "version": 8,
  "schema": 1,
  "min_reader": "0.18.0",
  "state": {}
}
```

### 필드 정의

- **`version` (주 세대)**: 문서의 주요 형식 세대입니다. 한 세대를 지원하는 앱은 해당 세대의 모든 개정판을 읽을 수 있습니다.
- **`schema` (개정 번호)**: 세대 내의 마이너 개정 번호입니다. 기존 문서를 깨뜨리지 않는 **추가적 변경**(새 선택적 속성 등)마다 1씩 증가합니다.
- **`min_reader`**: 해당 개정 규격을 온전히 읽을 수 있는 최소 Chemvas 앱 버전입니다.
- **`state`**: 실제 캔버스 드로잉 데이터(원자, 결합, 화살표, 노트, 설정)를 담는 객체입니다.

### 판독기 검증 순서

문서를 열 때 Chemvas는 다음 순서로 파일의 유효성을 검사합니다:

1. **형식 버전 검사**: `version`을 확인하고 지원하지 않는 버전이면 오류를 발생시킵니다.
2. **루트 객체 구조 검사**: 루트 필수 키(`type`, `version`, `schema`, `min_reader`, `state`)의 유효성을 검증합니다.
3. **개정 번호 검사**: `version`은 지원하지만 `schema`가 현재 앱이 지원하는 최신 개정보다 높다면, 더 최신 버전의 앱(`min_reader` 명시)이 필요함을 사용자에게 안내합니다.
4. **문서 본문 검사**: 캔버스 내부 요소의 유효성을 엄격하게 검증합니다.

## 적용 범위 및 계산 데이터 보존

- **적용 범위**: 순수 `.chemvas` 파일 및 편집 가능한 Chemvas SVG 내에 포함된 문서 데이터에 적용됩니다.
- **계산 데이터(Calculation Plan)**: 문서에 저장된 화학 계산 계획 데이터는 RDKit 설치 여부와 상관없이 온전히 보존됩니다. 문서를 저장하거나 CLI(`inspect-plan`)로 검사할 때 현재 드로잉과의 정합성을 확인합니다.
