# 문서 호환성

[English](DOCUMENT_COMPATIBILITY.md)

## 제품의 약속

앞으로 Chemvas를 업데이트해도 현재 지원되는 정상적인 **v7 `.chemvas` 문서는
계속 열 수 있어야 하며**, 저장된 그림과 문서 정보를 편집 가능한 상태로 유지해야
합니다. 지원되는 그림을 복구하기 위해 이전 설치본을 따로 보관할 필요가 없어야
합니다. 이는 임시 마이그레이션 기간이 아니라 계속 지원하는 파일 계약입니다.

기준은 2026-09-13에 지원되는 v7 계약입니다. 선택적인 전하·라디칼 표시 색,
거울상 평형 화살표, 입체배치 미지정 교차 이중결합 `double_either`, 이미지, 그룹,
원근 좌표, Calculation Plan v2를 포함합니다. 선택 필드가 없는 기존 v7 파일도
계속 지원합니다. 일부 과거 Chemvas 릴리스는 이 기능들이 추가되기 전에도 같은
버전 번호를 썼기 때문에 모든 v7 표현을 읽지는 못합니다. 이 약속이 이미 설치된
과거 앱의 읽기 동작을 소급해서 바꾸지는 않습니다.

문서를 여는 것만으로 원본 파일을 다시 쓰지 않습니다. 사용자가 명시적으로 저장할
때는 현재 출력 형식을 사용하거나 표현을 정규화할 수 있지만, 지원되는 저장 정보를
보존해야 합니다. 이전 설치본과 파일을 공유할 때는 원본을 보관하거나 다른 이름으로
저장하는 것이 도움이 됩니다.

## 저장 형식 변경

- 앱 릴리스 번호와 문서 형식 번호는 별개입니다. 현재 쓰기 형식은 여전히 **v7**이며,
  이 정책 자체로 새 스키마를 도입하지 않습니다.
- 기존 읽기 구현이 올바르게 해석하지 못하는 직렬화 변경에는 새 문서 형식 버전이
  필요합니다. 기존의 엄격한 스키마가 거부하는 새 필드, 새로운 열거 값, 필드 의미의
  변경도 포함합니다. 앞으로 호환되지 않는 기능을 v7 이름 아래 추가하지 않습니다.
- 향후 쓰기 버전이 바뀌어도 읽기 지원 버전에서 v7을 제거하지 않습니다. 버전 해석은
  GUI·CLI 소비자마다 따로 구현하지 않고 문서 경계가 소유합니다. 실제 새 형식이
  도입될 때 필요한 변환을 그 경계에 구현하며, 미리 추측한 마이그레이션이나 기능
  협상 체계는 추가하지 않습니다.
- 형식 변경을 출시하기 전에 지원되는 과거 고정 예제를 열고, 편집·저장·재열기에서
  정보를 보존하는지 검증합니다. Graph Patch처럼 입력 버전을 유지하는 출력 경로도
  점검해야 합니다. 새 정보를 v7로 잘못 표시하거나 v7에 맞추기 위해 조용히 버리지
  않습니다.
- 알 수 없는 버전·필드, 잘못된 문서, 유효하지 않은 참조는 계속 오류입니다. 의미를
  추측하거나 미지원 정보를 조용히 빼거나 검증을 우회해서 정상적으로 열린 것처럼
  보이게 하지 않습니다.

## 적용 범위와 한계

이 약속은 기본 문서 읽기와 편집 가능한 Chemvas SVG 안에 내장된 v7 문서에
적용됩니다. 클립보드 페이로드, CLI 요청·보고서, SVG 외부 메타데이터, 계산 전달
산출물에는 각자의 버전 계약이 있습니다. 기본 문서 형식이 바뀐다고 이 버전들이
자동으로 함께 바뀌지는 않습니다.

v7 이전 문서 지원을 추가하거나, 이전 앱이 새 형식으로 저장한 파일을 읽거나,
JSON 바이트가 같거나, 글꼴·플랫폼이 달라도 텍스트 픽셀이 같다는 보장은 아닙니다.
저장된 계산계획을 열 때 그 데이터는 보존하지만, 향후 화학 백엔드가 같은 결과를
재현하거나 미완성·오래된 계획이 실행 준비를 마쳤다는 뜻은 아닙니다. 과학적 검증과
문서 읽기 가능 여부는 별개입니다. 정확성·보안 수정에 따라 과거 구현이 실수로
허용했던 잘못된 입력은 계속 거부할 수 있습니다.

## 회귀 검증 기준

[`tests/fixtures/document-v7`](../tests/fixtures/document-v7)에는 사용자 연구 자료가
아닌 고정 합성 예제가 있습니다. 이 파일들의 버전은 숫자 `7`로 고정하며, 형식이
바뀔 때 현재 쓰기 코드로 다시 생성해서는 안 됩니다. 이들은 대표적인 검증 예제이지
모든 유효한 v7 문서를 열거한 완전한 명세는 아니므로, 도메인 검증 테스트도 계속
필요합니다.

[`test_document_compatibility.py`](../tests/test_document_compatibility.py)는 기본
파일 입출력, 편집 가능한 SVG, CLI의 정보 보존을 검사합니다.
[`test_document_edit_roundtrip.py`](../tests/test_document_edit_roundtrip.py)는
데스크톱의 편집·저장·재열기 경로를 검사합니다. 둘 다 `make check`에 포함됩니다.
과거 미지원 버전 테스트는 현재 쓰기 버전보다 낮은 모든 버전을 거부 대상으로 삼지
않고, 버전 1~6을 명시합니다. 쓰기 버전 상수만 바뀌었다고 v7 읽기 기준이 깨져서는
안 됩니다.
